## 完整性与边界

12轮均通过原始IndexedDB每store记录与blob哈希、完整工程manifest及所有未压缩条目内容哈希、revision、本地保存状态和底图renderCount不变检查。正式窗口及每个样本的refinementCount均为2且保持不变。导出ZIP外壳SHA因封装元数据不同未要求相同；不把外壳SHA变化当作工程内容变化。

原始书房负载含15张独立图像、2,121,728像素、137,955编码字节；岩岛含13张独立图像、8,208,384像素、310,023编码字节。该轮未测内存/资源峰值。

DOM与双rAF为主线程调度/提交代理，不是GPU或物理呈现完成。LongTask按原观察窗口保留，非函数CPU归因。所测四组负载与选择操作通过，不推定完整QA-PERF-04、其他浏览器或任意负载。

失败目录 selection-designed-verified 保留一次计数边界误判及原runner：正式样本内计数稳定，过宽检查误把准备/预热变化计入。完整12轮取自全新 setup-fixed 目录，不与失败批次混合。
