# 地图编辑架构整改设计

第一张验收图是一条沿山折返的路。作者从山脚向上拖出路线，把中段铺成石阶，再给临崖一侧加木栏。以后拉宽一个弯道，踏步和木栏都应该跟着这段路走，旁边独立摆放的路灯则留在原地。要做到这一点，工程需要记住作者把东西放在这里时建立的关系。

本设计用于后续整改。首轮聚焦画地图、编辑和复用。岩纹、洞口暗部、桥梁细部可以用贴图和光影画到合适的效果。涉及支撑、开口、通行或玩家可见性时，才需要相应的结构和校验。可进入的隧道、上下重叠的可行走空间，以及在平台上实际跑团，留到后续。现行实现与约束见[当前架构](../architecture.md)。

## 地形、正俯视与可旋转预览

作者在正俯视画布抬高火口北侧，应该当场从明暗读出新的山脊。沿山腰铺路，路面要落在刚刚编辑的坡上。点「斜俯视」转到山脚，应该能从侧面看到同一段隆起、同一条路和原先留出的栏杆缺口。一套主题提供岩石、积雪或木纹，两种视角使用工程里同一份形状和材质。

### 整改前的问题与依据

| 问题与依据 | 对制图者的影响 | 整改要求 |
| --- | --- | --- |
| **首要问题，火山的山形只在试作中完整出现。** 灰脊火口的山肩是整面 +1.8 米，坑底是整面 −0.4 米，沿轮廓另画崖壁。斜视试作额外塑造了连续坡面和起伏的火口边。试作的正俯视也因此更容易读出地形。 [火山样板](../../src/shared/generation/domains/volcano/natural-profile.ts) | 在现有工程里改玄武岩材质可以改颜色，却没有那段山脊可供移动。直接接入试作会让山路工具与画面认出不同的山 | 把采用的山形存入工程。正俯视明暗、斜视轮廓、放置落点和道路承托都由这份山形派生 |
| **历史缺陷，沿长坡画路却得到一截短梯。** 现有阶梯已能沿传入的完整路线分级，局部坡体也已有高程和承托查询。问题应从绘制手势一直查到最终接头。 [阶梯几何](../../src/shared/stairs/geometry.ts) · [承托查询](../../src/shared/geometry/support-sample.ts) | 只看阶梯两端或中心线，会漏掉折返、外弯悬空和手设宽度。转动镜头会暴露断口，换一张贴图也接不上 | 同一候选保留原路线、选中区段、两侧实际宽度和上下端落点。只在作者选择的区段铺阶，冲突在对应路段标出 |
| **原型限制，顶图缺少背面和底部。** 酒馆试作按已知物件名称选桌架、箱体等形状。桌面承托高度取自工程，桌腿造型来自试作规则。 [物件与外观](../../src/shared/model/scene.ts) · [附着高度](../../src/shared/attachments/contact.ts) | 换个主题或导入用户素材，同样的桌面可能配四条腿、两块板脚或一根中柱。按名称猜会画错，给每个主题另画一套又难以维护 | 让结构类型、尺寸、方向及可选侧面成为素材定义的一部分。模块给出默认值，实例可局部覆盖 |
| **接入风险，改变外观或重算地形时覆盖人工编辑。** 旧工程已有平地、固定素材、桥头链接、局部宽度和被手动删除的栏杆 | 打开旧图就重塑山体，可能让原路失去承托。同步新版桥栏也可能把登船口封回去 | 旧图按保存的地形和素材解释。重塑作为明确的编辑候选，预览受影响的路线、承托和锁，采用与撤销各一次。保存、重开和跨项目复制都保留实际内容与资源 |
| **接入风险，墙体渐隐或绕到背面可能暴露秘密。** 正俯视的遮罩、门窗和阴影已有受众规则，旋转会露出新的侧面 | 主持人看进公开餐厅是正常操作，同一镜头下的秘密门、密室、私密灯光或影子仍须保密 | 按受众、楼层和可见范围先取内容，再派生几何、投影、阴影和渐隐。玩家预览与玩家 PNG 使用同一份已过滤内容。 [玩家输出](../architecture.md#privacy) |
| **原型观察，第一次准备复杂地形会产生明显等待。** 火山首次出图约 1.3 秒，保留场景后切回约 0.012 秒 | 如果打开地图或每转一点镜头都重建山体，普通俯视制图也会承担这笔开销 | 默认俯视按需算地形明暗。首次切斜视才准备旋转所需的几何和纹理，拖镜头时直接使用已准备的内容 |

### 地形、物件和两种视角如何共用

**圈山脚和用笔刷抬地，两种入口都能画山。** 可以先圈出山脚得到基础山体，再用笔刷压出火口。也可以先刷出山脊，再调整山脚轮廓。两种起笔方式得到同一种可编辑地形，道路取高、正俯视明暗和斜视轮廓都读取最后采用的坡面。撤销刚才压出的火口，先前画好的山体仍在。

**地形保存形状，主题提供表面。** 普通平地沿用整面高程。需要起伏的山体保存已采用的坡面、边界及可继续编辑的塑形数据，保全算法版本和实际结果。承托查询已有实际表面、高度、坡面朝向和可行走属性，可以接入连续山体。在坡上画路时检查整段路面及其两侧。桥上的货箱和桥下的路即使俯视坐标重合，也能按各自的楼层与承托面定位。 [地形与岩坡的投影结构](../../src/shared/projection/types.ts) · [承托查询](../../src/shared/geometry/support-sample.ts)

**俯视画布也画出坡向。** 地形明暗取自同一坡面朝向、材质和地图光源。转相机时光源留在世界里的原位置。换成积雪会改变受光效果，山脊、坑底和道路高程由原几何决定。正俯视可以复用地形明暗图，改山形或移动灯光时更新受影响的坡面及投影范围。画布上的网格、手柄和局部宽度仍按世界毫米定位。现有画布与 PNG 有共同的场景投影入口，两种观察方向可从这里读取同一份受众可见数据。 [共享投影](../../src/shared/projection/projection.ts) · [画布与出图入口](../../src/platform/browser/render/renderer.ts)

原图上画好的崖边阴影和灯光也需要审阅。例如把旧火山改用真实坡面受光时，要在预览里核对原来的崖边暗带，避免同一处山壁被画黑两次。保留手绘暗部或改用随地形计算的阴影，应当是采用新表现时看得见的选择。

| 素材或对象 | 两种视角使用的资料 | 作者可以调整什么 |
| --- | --- | --- |
| 地砖、地毯、整张导入底图 | 原图贴到指定表面。完整底图按平面显示，圈选并标注过的物件可单独立起 | 材质、尺寸、旋转、落点 |
| 木箱、桌子 | 箱盖原图加箱高与侧板材质，四壁按长宽生成。桌面原图加桌架类型。具有承托组件时，摆件使用实际桌面或箱顶 | 选板脚或四脚，给箱子某一面加锁扣，改一张桌子的高度。带吸附关系的灯随承托面升降 |
| 树、墙、桥 | 树干以根点落地，树冠有冠幅和离地高度。墙取厚度与门窗位置，桥取桥面、支座、边栏和留口 | 树冠可选遮挡时淡出，墙可附视线组件。转到桥背面时，端头和手删的栏杆缺口仍在原位置 |
| 只有一个朝向的画稿、雕像 | 旧素材沿用固定图像及根点。需要从各面辨认的对象可补侧面、专用结构或模型 | 作者在预览里选择合适的表现，再存入「我的模块」供其他地图复用。 [固定素材的现有表现](../../src/shared/appearance/presentation.ts) |

<a id="terrain-choices"></a>

**给平顶木箱的俯视图选用「木箱」模板，默认开启「箱顶可放物件」。** 箱盖轮廓决定可摆放的范围，箱高决定油灯的落点高度。把灯拖到箱盖上时，画布预览吸附位置，松手接受后，搬动箱子就会带着灯一起走。制作圆顶宝箱或装饰用的箱子时，可以在右侧详情关闭这个选项。箱身换材质时沿用作者选定的设置。

生成提示词负责表达房间或区域的用途、摆设和画风，例如「这是备餐区，厨师从炉边取盘」。门是否开在墙上、盘是否吸附在台面、路能否接上桥头，交给手工与 AI 共用的关系和校验。首轮样板选火山与酒馆，再用不同主题的自制木箱和另一座桥检验复用，签收后才用采用过的工程更新首页成图。

### 作者怎样切换与出图

- **打开即正俯视。** 在正俯视布置、拖动和修改，点击「斜俯视」才准备可旋转预览。以当前楼层全景进入，围绕取景目标水平转动，俯角默认 55°，可在 30° 到 90° 调节。镜头是本次取景的临时状态，下次打开回到默认全景。
- **靠近房间，近侧挡住室内的墙逐渐淡出。** 转过墙角，原先的墙显回，新挡住视线的墙接续淡出。树冠由作者选择是否启用这个行为，树干可以始终可见。通行、视线阻挡和玩家保密分别读取各自的设置。
- **点「导出当前画面」保存眼前的 PNG。** 受众、楼层、取景、遮挡状态和光照与预览一致，按所选分辨率重绘。需要格网量距或 VTT 墙门坐标时使用等比例正俯视输出。
- **等待时保留二维画布，可取消。** 建议点击即有反馈，约 0.3 秒还没准备好再显示加载提示，首帧就绪才切换。已准备的几何和纹理可在同一地图版本、楼层及受众下复用。切工程、改地形或取消后的旧结果不得盖回新画面。斜视设备能力不足时仍可在原画布编辑和导出俯视图。

本地原型在 Windows、Ryzen 5 7400F、Radeon RX 9070 XT、Chrome 158、1600 × 1280 下，从正俯视已显示到首次斜视出图，每图测三次。酒馆为 0.14–0.31 秒，火山为 1.29–1.30 秒。保留同一场景后各测六次再次切换，约 0.012 秒。耗时主要在准备山形和贴图。手机、大图、持续转动帧率及正式工作台入口要分别验证。

### 接入次序与验收画面

| 顺序 | 从正常制图入口操作 | 观察什么 |
| --- | --- | --- |
| 先做正俯视的火山与沿山路 | 分别从圈山脚和抬高笔刷起步，换工具继续改同一座山。抬高北侧火口边，画折返路，只给中段铺阶并收窄一个弯。换雪地材质，再撤销、保存重开 | 两种起笔方式得到的山都能继续塑形、铺路和取景。正俯视可辨认迎光坡、背光坡与坑底。踏面和上下端落在实际坡面上，换材质保留手调宽度，旧样板可原样重开 |
| 再接相机和室内构件 | 绕酒馆转一圈，看桌腿、桌上灯、前墙与门洞。换到另一个主题，自制一只有正面锁扣的木箱，给桥栏留一个登船口 | 木箱背板、锁扣、承托在两个视角的位置一致。跨主题沿用结构规则。近景检查台面、桥头和接缝，再由作者看整图 |
| 最后核对玩家输出与交互 | 同一受众和镜位对照预览与 PNG。固定公开墙、遮罩和灯，只移动完全隐藏的物件及光源。试首次进入、再次进入、取消、换楼层和改图后重进 | 玩家画面的像素和导出元数据均不透露隐藏变化。重新进入能看到最新地图，准备失败仍能继续制图。桌面与移动设备分别记录首帧和转动体验 |

默认俯角和近墙渐隐距离留到样板验收时调校。用火山检查山脊和折返路是否清楚，用酒馆检查靠近房间时能否看清桌面与门洞。

## 对象有哪些部位，部位之间是什么关系

一条路画出来就有起点、终点、左边、右边和路面。一座桥有桥体、桥面铺装、两侧边缘和桥头。房间的每条边能定位到真实墙段，墙有厚度、两侧和沿墙定位的开口。即使土路两侧都空着，「右边」也已经是放置木栏或路灯的有效目标。木桥、石桥可以用不同的部件和材质预设搭成。栏杆的阻挡移动、阻挡视线与外观可分别设置。

| 关系 | 地图里的例子 | 编辑时应发生什么 |
| --- | --- | --- |
| 组成 | 桥体、桥面、桥柱和栏杆组成一座桥 | 选整桥能一起移动，选一节栏杆可以单独替换或删除 |
| 承托 | 山面承托一段道路，桥面承托桥上的物件 | 改宽、移动或平滑后，按实际路面宽度和落点复核支撑 |
| 附着 | 路灯沿道路右边排布，踏步铺在路线中段 | 跟随所引用的那一侧或那一段。独立摆放在旁边的灯保持原位 |
| 连接 | 道路末端吸附到桥头，桥头吸附到码头的接点 | 移动时预览两端能否继续接合，也能明确断开、稍后再接 |
| 共享 | 厨房和餐厅引用同一面墙 | 从任一房间选墙、改墙或开门，另一侧看到同一个结果 |
| 区域归属 | 鱼摊位于市集内 | 扩大市集边界可以把摊位纳入市集，摊位保留原来的世界位置 |

工程保存真实对象和部件、关系两端的身份，以及作者选中的部位。比如「右侧这一截」要能随路线变形定位，「删除这一节」要能在重新排布后识别。画布上的接近只产生吸附候选，接受吸附的落点才建立连接。图层负责整理、排序和编辑显隐，楼层决定对象所在的空间，高程和承托另行计算。

## 选区、删除与实例组件

删除范围由当前选区决定。只选餐桌就只删餐桌，同时选中餐桌和烛台就删这两件，选中「宴席」组就删该组及其成员。画布高亮与右侧对象树显示同一选区。搬桌时，吸附在桌面的独立物件会跟着移动。单删餐桌时，预览标出这些物件将解除的附着，撤销一次可恢复餐桌及原有关系。

对已附着的部件，锁定默认保护它相对宿主的摆放位置。例如把壁灯挂在门左侧并锁定后，平移整面墙两米，灯和光源随墙平移两米。要单独把灯挪到另一个挂点，先解锁壁灯。

作者可以直接在画布上给单个物件实例添加组件。例如摆下三个同款书柜，选中走廊里的一个，在右侧点「添加组件 → 视线遮挡」，沿柜背画线，再从门口预览柜后的可见范围。遮挡线只属于这个实例，随它移动和旋转。也可以在导入的木柜图上圈出可摆放花瓶的柜顶，同样的承托面可用于窗台、祭坛和货架。想在别处复用时，作者可以将改好的物件连同组件存入「我的模块」。

单个组件也可以直接跨项目复制。在项目甲选中书柜的「视线遮挡」组件并复制，然后在新标签页打开项目乙，或在同一标签页切换到项目乙，选中目标书柜即可粘贴。副本带入组件的参数、相对柜身画出的遮挡线，以及组件用到的固定资源和许可。目标项目为副本分配新身份，作者可以对照目标书柜调整遮挡线。若组件提供连接点，复制的是接点定义，实际连接在目标地图上建立。

## 沿山画路与露天开凿

1. 山地初始只有地形。作者选「道路」，从山脚拖到平台，样式给出默认宽度、铺面和栅栏设置。鼠标越出山面、在该高程没有承托时，画布标出放不下的区段，保留上一个有效预览。自动圆滑可以关闭，开启时也检查弯道两侧，避免圆滑后的路面切出悬崖。
2. 作者可以改整条路的宽度，也可以只改一截。使用默认宽度的路段遇到窄山肩可以自动收窄。建议在地形拓宽后让这段恢复到默认宽度。作者手设的宽度优先，空间不足时标出冲突位置，由作者改宽、改线或开挖。
3. 选一段或整条路铺台阶。台阶采用这段路线的实际长度、弯道、局部宽度和高程。假设入口与出口直线相距 5 米，作者画的是 20 米折返路，选择全段时，两个折返和上下端都要进入结果。检查要能指出哪段没有铺到、哪一端没有落地。
4. 普通画路沿用已有地形。碰到陡坡时，可以先用笔刷削出山肩，也可以主动选「开凿山路」，沿山腰拖出新路或指定已有路段。预览按每一截的真实路宽画出要削去的岩体、新露出的山壁和路面，同时显示坡度及两端与原路的高差。外弯若伸到悬崖外，标出缺少承托的那截，供作者收窄或往山里移线。采用和撤销各一次，地形与路段一起生效。将山路样式用到另一座山时，沿新路线取当地高程，再应用材质、踏步与沿边部件。
5. 用笔刷压低已有石阶旁的山坡时，拖动中先显示整笔将挖去的岩土，按每级踏面的实际宽度和固定高程检查承托。如果这笔会让三级台阶悬空，就把这三级标红，并在画布上给出「保留阶下岩土」。作者选中后，预览显示从山体伸出、托住这几级的岩肩，其余刷到的坡面按笔势削低。作者也可以收窄笔刷、换个位置继续挖，或取消这一笔。采用后一次撤销即可回到动笔前的山形和承托关系。
6. 开凿出来的平台属于山体。以后单选山路按「删除」，平台连同后来手修的边坡一起保留，可以接着画营地。撤销这次删除，路回到拆除前的位置。刚完成「开凿山路」就撤销，山体和道路一起回到开凿前的状态。若想恢复山坡，建议把「回填」作为单独的地形操作，以开凿前的坡面为参照，预览后来手修的范围及新摆物件的落点，再决定填哪一段。

### 建造游戏的地形工具

《过山车之星 2》允许调节笔刷大小和强度来抬高、压低、整平或切削地面。铺设穿过地形的园路时，地形会随园路变形，形成隧道。《都市：天际线 II》在规划道路时显示到终点的坡度。逐步降低道路标高时，先得到向天空敞开的路堑，再往深处才成为隧道。 [Frontier 建造指南](https://www.planetcoaster.com/player-guides/building-your-park) · [Paradox 道路工具说明](https://www.paradoxinteractive.com/games/cities-skylines-ii/features/road-tools)

织境可以用山腰驿站检验同一套地形编辑能否复用。先用大笔刷抬出山脊，再用小笔刷向下拖出一条露天沟。要在山腰建驿站时，建议让作者选「整平地基」，用房屋占地和门槛高程预览平台需要削去的岩土，以及门前能否接上山路。道路给出路线和各段宽度，驿站给出地基轮廓，两者都从采用后的地面取得承托。换成雪山主题，仍能在同一条沟或平台边缘继续动笔。

火山口和露天沟从上面看得见底，每处地表的高度就能表达这类起伏。山洞在同一位置同时有洞底、洞顶和上方山面。首轮的制图需求是从山路望过去能认出入口，可以让洞口贴合实际岩壁的朝向，用洞缘遮住路端，并给入口内壁加暗部。后续要在山腹里画岔路时，再引入可单独编辑的地下空间。

## 桥、道路与模块实例

**建桥有两个入口。** 可以选中已有道路的一段改成桥，沿用该段的走向并处理两端过渡。也可以从「我的模块」拖出独立的桥，再把道路接上。选中后都能改桥体、桥面材质和两侧部件。删除桥再新建会得到新实例，旧路端可以重新吸附。

**吸附决定是否建立链接。** 拖入吸附距离时，类型、楼层、高程和方向相容的接点自动吸附并显示接合预览。松手便建立链接。只是挨着放的桥和路可以各自移动。模块作者还可以在部件上标接点，例如给码头缺口指定「接桥处」。保存为模块后，每个实例按自己的位置和朝向提供这个接点。

**链接只带动能跟随的部分。** 已连接的桥挪动一点，路尾可以随之调整，画布直接画出调整后的路形。超出路尾可动范围、失去承托，或继续跟随会改动锁定路段时，显示红色断链和「放下将断开」提示。拖回有效位置可恢复预览。放下时，合法的桥移动与断链一并采用。若桥本身无处承托，则提示放置无效。撤销一次还原此前的形状和链接。

**桥柱和栏杆按部件排布。** 对定长栏杆，13 米长的可铺区使用 2 米一节的源件，默认排 6 节，余下 1 米留空，作者可以逐节调整。左侧原有四节时，作者删掉靠右桥头的第四节，再从右端加长两个节距，结果应是「栏、栏、栏、空、栏、栏」。整桥移动时，缺口随桥走。部件的稳定身份和局部位置承载这些修改，显示的「第几节」可以随排布变化。

**模块库是来源，画布上是实例。** 整座桥和单节带灯护栏都可以存入「我的模块」。实例引用固定版本并保存自己的实际部件和修改。作者发布新版后，用户选择要同步的实例。同步比较原版本、新版本和实例的人工修改，合入源模块新增的灯具，保留实例上单独添加的组件、手调部件、锁和已删除的栏杆。成员无法对应时，预览指出具体冲突，由作者决定。公共分享可在个人模块的制作、放置与同步体验成熟后再接入。

**更新原模块时可以逐项勾选实例改动。** 例如酒馆里的书柜加了视线遮挡，也刷了红漆。「更新原模块」列出这两项改动，作者只勾选遮挡组件并发布新版。以后从库里拖出的书柜使用模块原配色，带有这条遮挡线。红漆是酒馆这一个实例的外观，已有书柜仍由作者选择是否同步新版。

整桥在「素材 → 房间、建筑与桥梁模板」发布和同步。放置时，桥梁实例保存原模板的内容摘要。发布只把勾选的设置写入原模板的新版本，局部改动留在实例。同步时，按原模板和新版的差异，更新当前实例仍在继承的设置。排布照常沿实例自己的路线计算，手工删除的一整节保持留空。整桥的铺面、独立布置和路线几何可以随整桥另存，跨版本合并规则见[剩余事项](../roadmap.md#remaining)。

## 工业场景的构造与出图

从一段同时包含直跨、转折和桥头的试绘开始。先定路线净宽、平台高程、桥梁厚度和受力位置，再选择铺装、灯具及磨损。换一条走向和宽度都不同的路线，用同一套构造复画，并在同尺度的实际导出图里核对下列关系。远处建筑作为可换底图，可玩区的遮挡、支撑和通路由工程提供。

| 部位 | 设计依据 | 放大检查 |
| --- | --- | --- |
| 道路与桥头 | 每跨沿路线铺板，板缝在转角拼缝处收止。接续同规格铺装时，共用接头处的铺设基准。换材时在实际接头收口。桥梁承座、边梁和平台缺口以同一个接点和高程对齐 | 在两岸都能看出梁落在哪里、铺面在哪里交接、栏杆在哪里收头。换铺装后支撑位置仍准确 |
| 平台、崖壁与楼梯 | 同一段外露边界确定包边、立面上缘、栏杆底座和通行开口。转角共用节点，立面在实际邻台高程收底。钢梁包边根据各桥口的实际截面沿轮廓过渡 | 包边绕过转角，立柱落在结构上，玻璃和百叶立面连续至桥下，楼梯两端接到台面 |
| 设备与管线 | 设备提供进出接口。用一节直管和相配的转角、套筒沿线装配，安装高度和过道净空由实际位置确定 | 管线接到接口，转角内外连续，维护面和通路有足够净空 |
| 灯光与材料 | 指定发光体、照射方向和接收面。桥边导灯落到邻近路沿和路面，立面窗光沿窗洞和墙面展开。拼缝、踏步前缘和常走区域采用不同磨损 | 顺着亮处能找到光源，钢件边缘、粗糙铺地和玻璃有可辨认的受光差异，阴影显示构件之间的遮挡 |

工业场景的内置生成入口读取布局和固定素材，与手绘共用接合、承托和出图计算。能从空白工程复现的断边、堵口和错误叠压应修正共用构造规则，再用不同布局的真实出图检查。提示词适用于接入模型的制作步骤，可指定构图、构件用途、比例、灯色和照射面，并要求提供同尺度的局部候选。

## 房间共墙、视野与工作台

**拖墙和搬房间有不同的结果。** 拖厨房与餐厅之间的共墙，两间房一宽一窄，门仍附在同一面墙上。选中整间厨房搬离时，餐厅留在原位，预览把即将分开的共墙标红，并显示已有门窗最终挂在哪一面。对于归属有歧义的门窗，建议由作者指定去向，沿用其开关、锁和秘密状态。采用后两间各有完整墙体，撤销后恢复一面共墙和原有开口。

**视线遮挡是一项行为。** 墙和屏风都能提供遮挡，通行另按各自的设置计算。制图时，作者可以在走廊放一个临时视点，开关普通门，观察柜台后方的可见范围，也可以预览某个分区揭开迷雾后的画面。面向玩家的预览和输出先过滤秘密，未揭示的秘密门在墙上应呈现连续遮挡。氛围薄雾属于画面效果，保密遮罩决定哪些区域必须盖住。棋子移动、探索记忆和多人同步归后续跑团设计。

**画布与右侧详情共用选择。** 单击桥先选整桥，双击进入部件，Esc 返回上一级。也可以在右侧展开「桥 › 左侧护栏 › 第三节」。两条路径选中同一节，画布高亮和属性同步。拖画布空白处平移视口，拖对象预览地图编辑，拖面板调整停靠位置。「我的模块」「楼层」「详情」的布局属于个人工作区偏好。

**分区在同一张地图上编辑。** 同一楼层、同一级的市集与河岸可以共边，内部互斥。边界划过摊位，摊位随之改属。双击市集只是放大到这片区域，新画的井回到镇图仍是同一个对象。分区支持按范围选取、细画和局部导出。穿过两个区的道路保持连续，局部输出按区域裁切其可见部分。玩家能看到区内哪些内容，仍由受众规则决定。

## 从现有实现接入

共享层按关系计算哪些对象要跟随、哪些部位需要重算、哪些连接会断。手工工具和 AI 都把这组变化交给同一套工程命令，工作台只呈现候选结果。接入一种新木栏，只需描述源节、排列方式和阻挡属性，桥和山路都能使用它。需要引入新行为的例子是吊桥升起时改变通行状态。

| 切入处 | 建议的改法 |
| --- | --- |
| 道路与山体 | 从「道路」画布入口贯通手势、完整路线、分段宽度、真实承托和阶梯。现有阶梯已经沿传入的中心线求踏面，排查短梯时先对照作者画出的路线、交给阶梯的区段和最终承托。沿用已有露天坡体的校验和采用过程。 [道路与楼层模型](../../src/shared/model/scene.ts) · [地形承托](../../src/shared/geometry/support-sample.ts) · [阶梯几何](../../src/shared/stairs/geometry.ts) · [坡体校验](../../src/shared/terrain-inlay/scene.ts) |
| 边、端头与开口 | 让道路和桥提供可定位的两侧与端头，让墙提供带厚度及开口的边界。绘制、吸附、通行、遮挡读取同一份来源几何，再各自应用门窗状态等规则。将既有门路连接的接点与跟随经验用于桥路连接。 [墙体绘制](../../src/shared/geometry/wall-paint-geometry.ts) · [门前净宽](../../src/shared/geometry/doorway-clearance.ts) · [光影遮挡](../../src/shared/visual/projection.ts) · [门路连接](../../src/shared/path-attachments/contracts.ts) |
| 部件与版本 | 沿用沿线构件、真实成员、人工删除记录和固定素材身份。先在桥栏上做通单节编辑、改长和选定实例同步，再用同一节木栏沿山路临崖侧排布，检验复用。 [沿线构件](../completed.md#generation) · [素材与模板](../completed.md#assets) · [固定内容与身份](../../src/shared/library/content.ts) |
| 工作台与工程 | 画布和详情发出同一编辑意图，应用层准备候选，采用时重检工程基线、依赖、锁和预算。已有等宽道路按恒定宽度读取，已有连接按保存的引用读取。保存和备份保全实际部件、固定资源与局部覆盖，导入后能离线继续编辑。 [工作区布局](../../src/editor/workspace/WorkspaceLayout.tsx) · [工作区事务](../../src/application/workspace/workspace.ts) · [工程与保存](../architecture.md#storage) |

开发顺序先做通沿山画路、局部铺阶和露天开凿，再用桥路验证同一段护栏、连接和人工覆盖是否可复用。共墙拆合验证共享对象的身份，分区、面板停靠与模块同步可以分别交付。

## 交付时如何验收

以下是后续实现的验收场景。每个涉及工程内容的案例都从正常工作台操作，同时核对撤销、保存重开及备份导入后可继续编辑。

| 操作 | 通过条件 |
| --- | --- |
| 从山脚拖出折返路，开关圆滑，收窄一段并给另一段铺阶 | 整个选中区段及两端都有承托，平滑后的外侧也在山面内。人工宽度保留，冲突能定位到具体区段 |
| 在岩壁主动开凿，再撤销 | 同一预览能看清切口、路面和两端。采用后山路可连续通过，撤销一次恢复原山体与原路 |
| 开凿山路后，用笔刷把一处平台拓宽，在拓宽处摆一顶帐篷，再单选山路删除 | 路面移除，挖好的平台和拓宽处都保留，帐篷仍落在原处。撤销删除，山路回到平台上 |
| 在桥头前压低山坡，让三级固定高程的石阶失去承托，再选「保留阶下岩土」 | 拖动时整笔切口可见，只有会悬空的三级标红。选择后，岩肩沿手设宽度托住这几级，锁定的端点与桥头接合，斜俯视能看到两旁挖到的深度。采用后撤销一次，原坡面和原有承托同时恢复 |
| 给导入的俯视图选「木箱」，放置两只实例。在右侧关闭第二只的「箱顶可放物件」，依次把油灯拖过两个箱盖，再吸附到第一只上并搬动它 | 只有第一只箱盖显示吸附预览。松手后从斜俯视可见灯底贴着箱盖。搬动箱子、保存重开再搬一次，灯都跟随箱子，第二只仍沿用作者关闭的设置 |
| 把桥拖近两条路，只吸附一端，再将桥拖远 | 只有已连接端跟随，断链位置在放下前标红。取消拖动保留原连接，放下只断开预告的接头，一次撤销恢复桥、路尾和链接 |
| 删一节桥栏、延长桥、同步加灯的模块新版 | 末端短料留空，原位置的登船口仍在。只有用户选定的实例同步，新增灯具和手工修改可以同时保留 |
| 给一个书柜加遮挡并刷红，在「更新原模块」中只发布遮挡，再从库中放置一个新版书柜 | 新书柜带遮挡且使用模块原配色，酒馆实例保有红漆。此前摆放的其他实例可分别选择是否同步 |
| 复制单个遮挡组件，分别在新标签页打开另一项目、在同一标签页切换项目后粘贴到目标书柜 | 两种操作都能直接粘贴。目标书柜按自己的位置和朝向显示遮挡线，副本可独立调整。在目标项目撤销一次即可移除本次粘贴的组件 |
| 分别拖共墙和搬厨房，再从玩家视点查看 | 拖墙时仍是一面共墙，搬房间时得到两面独立墙。门窗归属明确，秘密门和私密注记在玩家预览、输出中受保护 |
| 双击市集画井，移动市集边界，再按区导出 | 镇图与分区指向同一口井，摊位归属随边界更新，跨区道路保持一条，导出范围与受众正确 |

| 场景 | 画布操作 | 建议的验收结果 |
| --- | --- | --- |
| 酒馆家具与布景 | 把餐桌、四把椅子和吸附在桌面的烛台编成「宴席」组，再把一只组外酒杯吸附到桌面。分别试搬桌、搬组、删桌与删组，每次撤销后再试下一项 | 搬桌时烛台和酒杯跟随，搬组时椅子也一起移动。单删餐桌后，烛台和椅子仍可在组内选取。删整组后，可单独选取原先摆在桌上的组外酒杯 |
| 屏风、玻璃隔断与壁灯 | 给屏风画遮挡线，给透明玻璃隔断设置通行阻挡。从门口预览视野，再把屏风移开一道缝。把二楼走廊的壁灯归入照明图层，锁在门左侧的挂点上，再拖动整面墙 | 玻璃允许视线穿过，通行检查识别实际占地。移动屏风后可透过缝隙看见后方。壁灯和光源随墙移动，灯与门的距离保持作者锁定时的数值 |
| 树林、菜园与废墟 | 选树种和密度画一片林地，手动把两棵树挪到营地入口两侧，圈出入口和营地的「留空」范围，再调高种植密度 | 新树只补在可种植的地方。入口两棵树采用作者摆定的位置，圈出的空地可供摆帐篷。菜园的田埂、废墟中的空场可用同一方式留出 |
| 设备与管线 | 在自制水泵上标出进水口和出水口，把一根管线吸附到进水口，另一根只摆在出水口旁。拖动或旋转水泵 | 只有吸附的管端跟随，画布预览接头位置和相邻管段的新形状。放下会断开连接时，接头提前标红 |
