# 自定义素材导入指南

从工作台「素材」打开「导入自有素材」或「批量导入图片／SVG」。先预览，确认后一次采用到当前工程；失败和取消保留当前工程。技术合同归[14](../14-visual-and-assets.md#custom-asset-import-contract)，许可要求归[10](../10-rules-assets-and-licensing.md#asset-review-and-rights)。

## 准备图片和名字

物件优先使用透明PNG；JPEG没有透明背景。也支持静态WebP和受限SVG。SVG不能携带脚本、远程图片、外部字体或其他外部资源；不支持的内容会被拒绝。动画图片和动态SVG不在本入口范围。

名称优先使用你填写的名字或清单里的`name`。没有清单时，默认只去掉文件名最后一个扩展名：`旧木桌_02.final.png`得到`旧木桌_02.final`。不会翻译、拆下划线、添加序号、去首尾空格或截断。同名素材可以共存，内部身份独立；只有确切相同的素材定义及来源才可能复用。名称不能全为空白，最多120个Unicode字符，不能含控制字符、双向控制符或孤立代理项；不合要求时会提示修改。

文件路径是另一项要求：最多128个UTF-8字节，使用规范NFC相对路径，不含`..`、绝对路径、反斜线、重复路径、大小写歧义或不能携带的文件名。路径检查不会替你改显示名称。

| 输入 | 保护上限 |
|---|---|
| 单张PNG、JPEG、WebP | 20 MiB；边长8192像素；3200万像素 |
| 单个SVG | 1 MiB；按固定处理器生成长边512像素PNG |
| 一个选定批次 | 64项；来源总量64 MiB；规范图片解码累计6400万像素 |
| ZIP | 压缩64 MiB；展开128 MiB；512条记录；不递归展开嵌套ZIP |
| `sceneweave-assets.json` | 256 KiB；1–64项素材；最多64份内联许可 |

上限不是可采用数量承诺。工程资源、来源保全和普通事务256项展开成本另行检查，超限整批拒绝。

## 标定尺寸和用途

先选择「独立物件」或「平铺材质」。图片名字不会决定行为：叫门的图片不会创建门，桥的图片不会授予通行，灯的图片不会自动发光。

| 字段 | 如何填写 |
|---|---|
| 图片／铺装宽高 | 物件整张图在世界中的大小；材质则是一轮平铺的世界大小，单位为整数毫米。可以先用真实图片比例计算高度 |
| 占地宽高 | 实际碰撞／净空使用的矩形，与透明留白、树冠大小分开 |
| 根锚X/Y | 从图像左上角计，落在世界坐标上的位置。单项同时留空时默认图像中心 |
| 占地偏移X/Y | 占地中心相对物件落点的偏移；默认零 |
| 阻挡移动／视线 | 分别确认。外观不自动授予这两种行为 |
| 绘制层／阴影类别 | 选择地面装饰、普通物件或冠层及相应阴影；不改变Floor、高程或实际占地 |
| 材质适用表面 | 从房间地面、墙面、地形、道路中至少选择一种 |

图片采用前会实际解码、规范为PNG并去除图片元数据。不会自动抠图、裁边或修改占地。静态SVG的实际原始源、规范源、处理器记录和PNG一起保全。组合与近侧视标定应通过完整素材库格式携带；原始图片清单目前只支持俯视物件和材质。

## 批量文件夹和素材包清单

可以直接选择多张图片、整个文件夹或一个ZIP。需要逐项预设名字和尺寸时，在共同根目录放一份名字精确为`sceneweave-assets.json`的清单。在界面可下载模板。多文件模式需把清单和图片一起选入；文件选择框通常只显示图片，可通过文件类型筛选显示JSON。

清单中的`path`相对清单所在目录，必须精确覆盖包内全部受支持图片。缺图、多图、重复映射、无效许可引用、未知字段或可选原始字节SHA-256不匹配时，整个读取失败；修正后重新选择文件。

```json
{
  "format": "sceneweave-asset-pack",
  "schemaVersion": 1,
  "pack": {
    "id": "my-room",
    "name": "我的房间素材",
    "version": 1,
    "style": "手绘",
    "scenes": ["室内"]
  },
  "licenses": [{
    "id": "my-license",
    "text": "替换为这些图片实际适用的完整许可文本。",
    "attribution": "替换为作者及实际来源。"
  }],
  "items": [{
    "path": "木桌.png",
    "name": "木桌",
    "kind": "prop",
    "widthMm": 2000,
    "heightMm": 1000,
    "footprintWidthMm": 1800,
    "footprintHeightMm": 800,
    "rootAnchorMm": { "x": 1000, "y": 500 },
    "footprintOffsetMm": { "x": 0, "y": 0 },
    "blocksMovement": true,
    "blocksSight": false,
    "renderLayer": "object",
    "shadowClass": "furniture",
    "tags": ["桌子"],
    "licenseId": "my-license"
  }, {
    "path": "旧木板.png",
    "name": "旧木板",
    "kind": "material",
    "widthMm": 1000,
    "heightMm": 1000,
    "applicableSurfaces": ["room", "terrain"],
    "tags": ["木板"],
    "licenseId": "my-license"
  }]
}
```

这是一份结构示例，许可占位文字不构成授权。清单只预填草稿，用户仍需核对并明确确认嵌入权利。清单不接受`approved`、P3、原创身份、外部许可URL或自动授权标记。

## 预览、采用和跨工程使用

1. 选择文件，核对名称、图片尺寸、物理占地、根锚及用途。批量可以取消选择某些项，也可以修改独立许可。
2. 填写实际署名和完整许可，明确确认有权把所选素材及许可嵌入、分享于工程。清单许可也须确认；工程嵌入权不等于公开默认素材包的再分发权。
3. 点击预览。规范PNG、固定定义、许可、来源、预算及完整工程都通过后，才出现可采用候选。预览不修改工程。
4. 一次采用，在当前工程里放置物件或应用材质；可撤销整个批次。保存与冷读继续检查实际资源和许可。
5. 要跨工程复用，在「当前工程」选择素材并保存到「我的素材」。再用个人素材库备份携带到其他设备；工程备份与个人素材库备份各自保全其内容。

导入不会自动覆盖同名素材或写入个人库。个人导入无需等待公共素材P3；公共主题包则要分别完成来源、技术、美术、场景覆盖审核，以及用户对确切内容的签收。审核记录保存在当前站点本机，可另行导出声明；素材包和工程不会自动携带可信审核状态。

## 处理质量初筛提示

每次准备新素材都会读取实际像素。完全透明的图片不能采用；低清晰度、疑似矩形背景、留白过大、可能裁边、材质透明孔洞或疑似平铺接缝会列出图片和原因。存在提示时，采用按钮先禁用：可以取消、换图或修正尺寸后重新预览；若这是有意的像素画、照片、透明覆盖或贴边图案，可逐件勾选确认保留。没有默认全选或清单免检标记。

确认只对当前确切图片、名字、用途和尺寸有效；取消重建、换图或重新绑定AI草稿后需要重新确认。初筛不会自动裁边、修改名字/占地，也不会自动调用AI重画。完整工程备份及旧工程仍按原完整校验打开，不会因新初筛提示丢失旧素材。初筛无提示也不表示美术或完整场景已经通过。

## 核对和审核素材

导入采用后，在「素材」展开「本工程素材审核」，点击「准备本工程素材审核」。准备会完整读取当前工程素材及其依赖，不修改工程。勾选要核对的素材，分别记录来源与权利、技术与标定、美术、场景覆盖的结论、评审者和证据；没有检查的维度保留「未检查」。用户签收单独记录，不会因为技术通过而自动变为已签收。

「主题素材包」可以按主题、场景或画风查找，显式加载一包后勾选需要的材质、物件或组合，再预览采用。每包另有两份可编辑场景可下载，经工程导入打开。当前六包均为候选，完整主题要求在面板保留待审项；审核应结合实际场景、比例与用途逐项检查。素材、依赖、主题或代表场景改变后，旧审核不再自动适用于新内容。
