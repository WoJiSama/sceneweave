<a id="remaining"></a>
## 已知缺口

| 事项 | 剩下要解决什么 |
|---|---|
| 性能与容量 | 弱网下立即确认新建，首个可编辑画布仍要等待公共画布、编辑命令和完整工程校验代码下载。待扩大实机和复访覆盖，缩短 2000 物件分组的候选准备，并核对冷开已有工程后的首次落盘。500 物件已测交互结果仅适用于对应负载。短阶段的进程内存与显存峰值仍缺样 |
| 海洋成图 | 新船外观、逐潮号三层及近岸与远洋成图待用户签收与发布。旧 Windows WebKit 26.0 的固定 SVG 间歇性失败待稳定复现与定位，真实 Safari 待验证 |
| 岩体与山路 | 潮环岩岛与默认沿海候选的崖壁、坡面及两段石阶接合待用户按整图和局部签收。继续增加主山体与环山路线的构图变化 |
| 俯视地形与斜俯视预览 | 缩短高分辨率近景贴图重烘耗时，在移动实机复测大图首帧、转动帧率和内存，复核不同 GPU 在重烘期间的瞬时峰值，收集样板美术签收。视角及制图用例见[整改设计](reference/map-editor-refactor.md#terrain-views) |
| 图片整件质量 | 继续验证不同木板纹样的局部接续与边界明暗，缩小小件移开后的残影和铜沿物件换底后的色边。真实操作者分阶段修正用时及新手操作稳定性待测 |
| 整图视觉 | 余烬旅舍等光照样板、碎潮礁湾的海岸轮廓和海港林缘的植被布置，以及海岸与火山的默认直出成图待用户签收 |
| 工业赛博朋克视觉 | 碧脉冷却枢纽与暮港吊运环线待用户按全图与接合局部签收。不同厚度的梁共接一个平台时，仍需核对包边跨多个转角与邻台高差的遮挡。见[构造设计](reference/map-editor-refactor.md#工业场景的构造与出图) |
| 真实AI收益 | 用不同通用助手和跨题材需求验证冷启动首图 40 分钟交付线，记录首次真实预览、完整交付、返工和人工接管。另用相同需求比较实际用量与缺项 |
| VTT兼容 | 在明确版本的Foundry和导入器中真实导入，核对比例、墙门、秘密、灯光和玩家视角 |
| 使用交付 | 观察真实主持人在桌面与窄屏首次备团的入口发现、完整交付耗时和人工接管；继续覆盖目标移动设备与浏览器的下载恢复、上桌反馈及公开分发前检查，只声明实际验证的组合 |
| 全图画风 | 新图材质笔触、室内及林地首生成的铺装与地表，以及室内外手绘、茶绘和线稿样图待用户签收。林地开阔处的层次和瓦砾、室内使用痕迹与局部光照仍可细化。自动候选目前按结构与家具反馈决策，成图构图仍由用户看图审阅。压缩位图的低对比细线可能断开，局部补画的画质和接缝待使用已配置的图片模型核对 |
| 生成图的植被与地表密度 | 混合场景仍需加密林缘与林下地被。自然地形和组合地貌待按干湿、坡度和材质安排植被及碎屑，优先补足森林河谷。营地的矮草在整图尺度仍可细化，程序成图待继续收集美术与移动设备容量反馈 |
| 秘密房间视觉 | 公开房间内部可保留，但房间轮廓之外的公开边缘与无归属独立墙仍可能被遮罩覆盖；异形房间、复杂墙接头和块石墙继续保守覆盖，墙边接合、室内视觉和用户美术签收待完善 |
| 工作台维护 | 区域候选、选择与历史等协调仍集中在Workbench，继续按可独立测试的职责拆分 |
| 后续扩展点 | 在相应需求启动时，分别定义自定义算法的候选输入输出、图层的玩家可见投影，以及团务规则可读写的数据。插件市场的分发流程留待后续设计 |
| 道路转桥与模板版本 | 扩展已有局部宽度、阶梯或外部依赖的道路转桥。整桥模板的铺面、独立摆件和路线几何仍需跨版本合并规则。范围与验收场景见[整改设计](reference/map-editor-refactor.md) |
| 跨组移动与房间复用 | 跨独立地形组的道路、坡道及共用边缘仍需先处理共同支撑，才能单移一侧地形。房间模板仍需支持完整组层级、墙面挂接和绑定窗光的跨工程复用。含近侧视承托物件的模板只支持原朝向放置 |

既有实现可以继续使用；以上条目仅保留未解决部分。新的功能扩展先明确用户任务和最小结果，不从样板缺件自动扩大产品范围。

## 制作与开发的接续

图片任务先读[图片步骤](reference/image-item-workflow.md)，地图或局部制作先读[制作总则](reference/project-creation-workflow.md)。当前模型和事务约束看[架构](architecture.md)，素材权利和导入看[素材说明](assets.md)。

开发时选择受改动影响的检查即可；一个能力完成相关检查后可以独立交付。公开发布、外部调用和用户签收按当前授权处理，不继承旧会话授权。
