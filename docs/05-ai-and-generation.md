# AI 流式对话、工具创作与渐进同化

状态：2026-10-23 用户确认设计，尚未实现。当前应用仍为 `0.2.0-m1-d2`、严格 v6 完整工程/有效 v3 场景，没有 AI 任务服务、对话工具循环或运行时 SVG 编辑。实施交接见[45](45-ai-authoring-and-unified-v1-plan.md)，顺序见[07](07-roadmap.md)。旧“图像素材优先＋可选M2-L”的排期由本页替代；历史运行报告保持原样。

## 1. 第一版目标

主入口是流式对话。用户描述场景、局部修改或素材风格，AI 使用项目内技能与受支持工具，在隔离任务草稿中多步制作、检查和调整；用户能实时看进展、打断或追加要求，最后审阅差异并一次采用。手工编辑、保存、素材使用和 PNG 导出继续不依赖 AI 在线。

第一版只接对话 API，不接生图/图像编辑 API。场景保持语义实体可编辑；新素材可由模型输出受限 SVG，或通过既有参数生成固定派生外观。SVG/场景导出 PNG 使用本地渲染。模型看图能力单独探测，不从“有对话接口”推定已支持。

单件→组合→明确选区/图层的渐进同化保留为工作流。风格任务只开放外观字段；场景创作任务才开放已实现的结构/布景工具。它们共用任务机制，不因使用同一个模型而共享全部权限。完整像素绘画、任意代码执行、主工程云同步与生图 API 留待后续。

## 2. 前后端职责与网络

| 执行位置 | 责任 |
|---|---|
| GitHub Pages / 浏览器 | 静态界面、主工程和个人目录、手工工具、实时草稿预览、差异/保护点/最终采用、撤销与 PNG |
| 自有服务器 | Node.js + Hono 任务服务、provider 密钥和协议适配、技能加载、模型与工具循环、预算/取消、鉴权、事件和检查点持久化 |
| 共享 TypeScript 核心 | 完整类型、整数毫米、命令/作用域/锁/引用/几何校验；不依赖 DOM、React、HTTP 或 IndexedDB |
| 执行适配器 | 服务端执行纯领域步骤；需要 Canvas/解码的操作交给已连接浏览器，结果带任务/步骤/草稿身份并校验；最终本机校验不能因服务端已校验而省略 |

线上后端通过 HTTPS 提供受控 API。Origin 精确配置到协议/主机/端口，不包含 Pages 路径；浏览器还需有效应用访问凭据。应用凭据与 provider key 分开，凭据不放 URL。首版维护者自用，不提供匿名公共代理；拒绝跨任务读取、未经授权调用和越限请求，服务端固定允许的 provider 地址/模型。

前端构建只含后端公开地址。provider key 只从服务器受限配置或环境注入，不进入工程、目录、前端 bundle、IndexedDB、截图、Git 或日志。模型/用户输入不能改变 endpoint、请求头或外联地址。不开通任意抓取、文件路径或 shell 接口。开发期可使用 localhost 后端，生产不用公网 Pages 访问回环网关作为默认方案。

## 3. 技能与工具

技能是可版本化的工作说明：目标、适用情形、步骤、示例和检查标准，例如俯视素材制作、建筑布景、墓园风格或渐进同化。由项目维护，任务记录技能标识/版本。模型可选择适用技能，技能不能增加权限；素材名称、导入文字和用户内容不能伪装成系统指令。Codex 本机已安装的技能不会自动接入应用。

工具是有严格参数和返回值的真实 API。任务服务向模型声明本次可用子集，拼装完整调用参数后解析、执行，将成功或结构化失败结果返回模型再继续。流式输出只负责显示和传输，不直接写主工程；不执行半段 JSON，不接受任意 JSON Patch 或整份模型文档替换。

| 工具组（语义，精确schema在实施切片冻结） | 允许的能力 | 边界 |
|---|---|---|
| 场景/目录读取 | 场景摘要、明确对象/范围、固定素材检索、尺寸/来源/许可 | 只读上下文不自动成为可写范围；不读用户全盘或未选个人库 |
| 放置/调整/参数 | 独立物件、组合成员、已有有限外观参数 | 固定定义、显式支撑、完整依赖/锁；同化不改布局或物理语义 |
| 建筑/室外 | 逐步接入已支持的绘房/共墙/附着门窗、地形/道路/连接/散布命令 | 几何工具返回真实实体和完整依赖；图片不证明通行；不开放未验证的任意拓扑重写 |
| SVG 制作/派生 | 创建或修改受限静态 SVG，规范化并生成固定位图候选 | 保留原件、实际源/派生字节与许可；不运行脚本或远端资源 |
| 预览/诊断 | 校验草稿、渲染指定受众/范围、返回摘要与可用截图 | 截图外发另按上下文授权；视觉模型支持须实测，失败不能伪称“已看图” |
| 快照/交付 | 请求草稿检查点、准备采用差异、准备本地导出 | 模型不直接采用主工程、不代用户下载或公开；历史局部恢复仅用已实现策略 |
| GM 文字 | 新建 GM 注记、修改明确选中的既有 GM 文字 | 已公开文字的改写先形成 GM 草稿；不自动公开、揭示秘密或解锁 |

首次闭环从只读、单件放置和调整开始；其他工具通过各自真实校验后逐组启用。初版不开放删除既有实体、任意全场替换或修改编辑锁/可见性。草稿中新生成步骤可通过草稿撤回重算，不必赋予模型删除主工程对象的权限。

## 4. 任务、流式事件与暂停

创建任务固定 `taskId`、协议/技能版本、主工程身份与基线、范围和允许工具、上下文受众、资产固定版本、预算。服务端草稿有独立 `draftRevision`；它不是主工程 revision。工具调用绑定 task、step/call ID、执行代次和预期草稿版本，重复结果只消费一次。

首版采用 HTTPS 请求与 SSE 事件流，浏览器以 fetch 流读取以携带鉴权头；任务创建、补充要求、暂停/取消和查询通过受控请求。事件至少区分文字增量、工具开始/结果、草稿更新、状态、用量和错误，带单调事件序号。断流后从确认序号恢复；缺口先取完整检查点，不用半份增量拼主工程。具体路由/字段由M2-1冻结。

状态语义：准备→运行→等待浏览器/等待补充或暂停→检查→可采用；失败、取消、已采用和基线过期分别展示。用户打断先中止当前执行代次，保留最后有效草稿；追加指令后新代次继续。取消后不自动重开任务，迟到的模型/浏览器结果丢弃。

SQLite 与制品目录保存任务元信息、必要上下文/对话、步骤和检查点，供重连或显式继续；日志只记录脱敏的状态/耗时/用量。保留期、删除、磁盘预算和过期策略在M2-1实现前固定并展示，不能无限积累。任务正文访问受任务归属保护，默认不作为调试日志或工程附件。

浏览器断线不是取消所有服务端计算，也不保证任务能完全继续。需要浏览器渲染、解码或资源时进入等待；重连校验身份后继续。服务重启从已确认检查点恢复为可查询/暂停状态；未知是否已经完成的付费请求不自动重发。

## 5. 草稿、最终采用与局部恢复

服务端只持有用户授权的任务工作副本；主工程留在浏览器。步骤先通过范围/锁/几何/依赖和资源验证，再形成草稿的新完整状态。前端清楚标出“AI草稿”，可查看当前主工程和差异；任务执行期间不制造主工程撤销记录，也不逐个物件要求确认。

最终采用由用户触发：验证任务/草稿来源和完整差异→核对当前主工程基线、读写集合和资源→保存保护点→重新核对源/场景/元数据CAS→一次原子采用，主工程 revision 加一，并有一个撤销单位。保存/保护失败按06保留内存、持久分支和成果，不显示假成功。

等待期间的手工编辑、撤销/重做、重开、切工程使旧基线采用失效。保留草稿供查看或导出为独立成果；重新采用须在新基线上重建候选并复验。首版不自动三方合并，也不把旧AI整体文档覆盖回来。

最终事务最多256条实际展开命令，成员/依赖计入同一预算；草稿多轮执行不能绕过最终采用上限。超限要求缩小范围或明确划分下一独立批次，不能用自动拆提交伪装“一次采用”。部分采用须重算完整依赖组、整体校验后再显示可采用，不能删掉失败依赖来凑成功。

采用后的结果沿用既有撤销、命名快照和适用局部恢复。恢复生成当前文档的新事务，保留范围外新编辑；范围、锁、实际资源、保护点与CAS继续检查。现有建筑结构仍受会话连续性限制，现存室外实体受出生/拓扑身份限制；新v1不自动提供持久建筑或任意拓扑恢复。

## 6. 场景与几何规则

模型提出用途、布局和素材意图；程序以整数毫米和受支持命令生成可编辑实体。共墙唯一，门窗引用稳定端点/真实墙段，支撑表面显式，依赖闭包包含邻室/开口/物件/注记，越出授权范围即失败。硬约束来源由应用保留，模型不得降低尺寸、移除入口或改成软约束。

手工草稿可以暂未连通；AI任务声明完成的普通必达房间必须满足真实入口的结构连通。明确隔离要有用户需求依据，不能将 required 改成 unspecified 来通过检查。门锁、编辑锁、结构连通、当前通行和家具净空分别验证；当前有限净空检查不冒充全图寻路。BSP、A*或通用布局求解器按实际需要另定，不要求先造完整生成器才能接入现有领域工具。

新场景任务使用新/空草稿；已有场景按明确选区及依赖修改，不能由“生成场景”推定允许替换全部已有内容。秘密几何、公开关系和遮罩由核心检查，新GM内容不能先创建成公开再期待秘密门遮住。通用连续高程、城镇路网、任意复杂结构重生成尚无承诺。

## 7. SVG、素材与渐进风格

SVG是可编辑素材源，不是场景物理模型。首批静态子集和复杂度上限在M2-0合同及M2-4实现中冻结；拒绝DOCTYPE/实体、脚本、事件属性、foreignObject、外部URL/字体/样式、动画、未支持滤镜和过深引用。仅允许受限本地定义引用，限制字节、节点/路径/坐标、尺寸、像素和总解码预算。解析规范化后隔离栅格化，不把模型SVG作为应用DOM执行。

源SVG、规范化内容、固定派生PNG、hash、处理器版本、来源/许可及物理标定一起保存，实际像素与源对应。旧默认源和用户固定版本不原地覆写。源→派生→采用均有界校验，工程和完整素材库备份要可离线重开；只存prompt/seed/远端URL不算完成。

同化按单件确认风格→一个组合逐成员→明确多个组合/选区/图层推进。每次扩围冻结新的目标ID、风格基线、允许字段、排除项和预算；不沿同定义/同标签/邻接关系传播，不影响后来入层对象。只读层选区与持续图层外观规则分开。

外观任务保留成员身份、位置、占地、支撑、通行、编辑锁、秘密、人工移动/删除/排除和未选覆盖。不能把组合烘焙成单张图冒充可编辑组合，不能因换图推断碰撞或尺度。新素材物理尺寸/锚点/占地须明确标定并审阅；既有实例外观派生默认沿用既有物理值。

入库和采用是不同事务：用户可只保存固定素材，或在确认后应用到场景；任务中产生的临时资源先归草稿，未采用前不修改共享默认目录。失败/取消后按任务保留期处理临时资源，不能回收工程或快照仍引用的字节。

## 8. 隐私与来源

发起时展示发送给自有服务器和转发给provider的内容范围，两层边界分别核对。服务端可能需要完整工作副本做校验，模型只收本次必要且已授权的上下文；不能将“后端持有”当作“可以向模型全部发送”。默认不发GM秘密、无关库或历史；确需GM上下文由用户明确选择，GM表示对玩家保密，并不自动代表允许外发。

公共素材候选只用许可允许且公开的参考。私密布局/文字可能进入SVG内容或像素，清除元数据不够；受私密来源影响的结果保持相应限制，不自动成为公共素材或玩家输出。公开文字改写先存GM草稿。玩家图继续先过滤内容再派生/渲染，不带源SVG、对话、任务ID、私密名称或生成来源元数据。

名称、标签、注记、导入源和模型说明均是数据，不增加工具权限。模型输出用纯文本/受限Markdown显示，不执行HTML或自动加载外链。许可核对包括参考外发、派生、嵌入和分发条件，未知不能标为允许；模型自述版权不构成依据。

采用成果只记录必要的工具/model、技能版本、源引用、日期和处理摘要；完整对话/任务上下文留任务存储，工程不带隐藏推理、凭据或本地私密路径。任务存储生命周期和日志脱敏均需实测。

## 9. 预算、错误与能力探测

每工程同时最多一个活动AI任务，任务内写步骤串行。模型轮数、工具总次数、文本/输出token、SVG及制品字节/像素、任务磁盘、墙钟期限、重试次数均有显式上限；与现有工程预算取较严值。精确初值须在M2-1/4开始前冻结并验证，不能以“模型还在工作”为由无限重试。超时/限流/缺资源/存储失败保留最后有效草稿，不能把不完整内容标为ready。

只在明确可重试且总预算允许时有限重试；已经发送但状态未知的请求不盲目重复。取消不能承诺供应商退还已发生费用，实际用量未知就显示未知，不按零计。工具校验失败可作为结构化反馈让模型在原范围和预算内修正；不能通过修正回合增加权限或解锁。

用户提供渠道目前仅完成 `/models` 鉴权和浏览器访问探测。M2-0/1要实测流式文本、分片工具参数/ID拼装、至少一轮工具结果续答、错误/断流/取消与用量；视觉输入另测。官方模型文档不能替代中转渠道证据，也不调用生图API来证明对话可用。
