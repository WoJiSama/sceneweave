本文只维护当前AI权限、任务协议和采用合同。配置基线为文字 `glm-5.3`、视觉 `glm-5.3-flash`，视觉能力仍为 `unverified`；完整Q4和地形真实任务尚未验收。旧请求、失败、测试及发布记录见[AI历史台账](archive/ai-validation.md)，本地实现不等于线上已更新。

## 1. 能力与非目标

主入口是流式对话。用户描述场景、局部修改或素材风格，AI 使用项目内技能与受支持工具，在隔离任务草稿中多步制作、检查和调整；用户能实时看进展、打断或追加要求，最后审阅差异并一次采用。手工编辑、保存、素材使用和 PNG 导出继续不依赖 AI 在线。

第一版只接对话 API，不接生图/图像编辑 API。场景保持语义实体可编辑；新素材可由模型输出受限 SVG，或通过既有参数生成固定派生外观。SVG/场景导出 PNG 使用本地渲染。模型看图能力单独探测，不从“有对话接口”推定已支持。

单件→组合→明确选区/图层的渐进同化保留为工作流。风格任务只开放外观字段；场景创作任务才开放已实现的结构/布景工具。它们共用任务机制，不因使用同一个模型而共享全部权限。完整像素绘画、任意代码执行、主工程云同步与生图 API 留待后续。

| 执行适配器 | 服务端执行纯领域步骤；需要 Canvas/解码的操作交给已连接浏览器，结果带任务/步骤/草稿身份并校验；最终本机校验不能因服务端已校验而省略 |

**程序底图链路：** 工程面板默认本机Worker，可明确选择服务端生成。独立`POST /v1/terrain/basemap`与Worker调用同一确定性核心，不创建AI任务、不调用模型；只发送新空白候选、生成设置、固定素材元数据及用于校验的当前工程标识，不发送当前地图内容、历史或图片，应用凭据仅在页面内存。两端绑定算法/配方版本、规范化输入、固定素材与结果指纹；[精确传输合同](04-scene-document.md#program-base-map-protocol)归04。浏览器继续完整重放、真实资源物化与成本复核，候选可独立预览/导出/采用；先保全当前保存，再保存并冷读新工程后切换。取消、迟到、过期和超预算不写当前工程，服务失败不自动改走另一条路径。[运行方法](../CONTRIBUTING.md#program-base-map)沿用自有后端的鉴权/Origin配置。

**后续整改目标（已确认，待实现）：** AI在上述确切物化底图上继续授权内修改，绑定真实完整hash、主工程基线与草稿身份，沿现有保护点/CAS、一次采用和撤销链路交回；失败可保留合法底图，未知计费请求不自动重发。程序底图生成与后续AI修改分别设置额度，同时保留完整累计账本，以及覆盖整个流程的计算、资源和时间上限；最终一次采用仍检查全部实际影响。这个目标显式调整原先共用一个256额度池的方案，分类数值和全流程上限尚未确定，规则归[04的预算演进目标](04-scene-document.md#capacity-budget-evolution)。

**现行实现边界：** AuthoringStart与重放仍从0计成本，底图会话回执没有自动变成AI账本，现有入口继续执行256限制。接续实现须绑定分类额度、策略版本、确切底图及可重放初始账本，保留生成与AI的全部成本；不能直接清零后发起第二段，也不能为留额度暗减硬约束或更改冻结算法。当前固定样本成本与余量归[地形台账](archive/terrain-validation.md#program-base-map-20261029)。具体任务与移交条件只在[开发整改计划](07-roadmap.md#development)维护；不包含生图API或任意代码执行。

线上后端通过 HTTPS 提供受控 API。Origin 精确配置到协议/主机/端口，不包含 Pages 路径；浏览器还需有效应用访问凭据。应用凭据与 provider key 分开，凭据不放 URL。首版维护者自用，不提供匿名公共代理；拒绝跨任务读取、未经授权调用和越限请求，服务端固定允许的 provider 地址/模型。

前端构建只含后端公开地址。provider key 只从服务器受限配置或环境注入，不进入工程、目录、前端 bundle、IndexedDB、截图、Git 或日志。模型/用户输入不能改变 endpoint、请求头或外联地址。不开通任意抓取、文件路径或 shell 接口。开发期可使用 localhost 后端，生产不用公网 Pages 访问回环网关作为默认方案。

### 2.1 生成与AI分类账本（目标合同，待实现）

本节细化已确认的分类额度目标；现行`AuthoringStart/State/Draft`仍为schemaVersion=1，`sceneweave-base-map@1`及256公式保持。语义单位、操作/累计/最终采用边界只在[04](04-scene-document.md#capacity-budget-evolution)定义。本节不预定新额度数值，也不把现行底图会话回执视作可接续凭证。

| 分类或保护 | 目标规则 |
|---|---|
| 程序生成`G` | 完整底图真实展开计入生成额度；不占后续AI编辑额度。生成失败不产生可采用的半份底图，已花计算和时间保留在执行消耗中。 |
| AI修改`A` | 从确切底图开始的受支持成功操作逐项累计；生成成本保留在同流程账本的`G`中，不能重置或挪到`A`。同一对象多次操作、no-op和改回继续累计。 |
| 完整采用 | 以完整最终结果检查一次采用影响、资源、锁和基线，不能将生成和AI拆成多个自动提交规避。AI失败或取消时，合法底图可作为明确的独立结果供用户预览/采用。 |
| 全流程执行 | 生成、预演、AI调用、资源物化、重放和采用准备的实际工作均受计算/资源/时间保护；模型请求、工具尝试、输出和制品另有累计上限。只读预演或失败不扣成功编辑量，也不退还已执行消耗。 |

**接续必须绑定的内容：**

| 对象 | 必需绑定与校验 |
|---|---|
| 冻结策略 | 策略ID/版本/hash、完整限额、适用流程与前后端能力；任务创建后不可改数值。更换策略必须另起明确任务，不能在旧账本中途换算法。 |
| 底图来源 | 流程ID、原始空白及生成请求/完整结果、算法/配方与固定素材指纹、真实资源闭包、实际身份分配及准备时间，绑定领域结果hash和本机物化后的完整projectHash。只有seed、实体数量或`initialOperationCost`摘要不够。 |
| 逻辑步骤账本 | 连续序号、唯一操作ID、生成/AI分类、原始受支持操作、前后内容hash、实际语义目标与各可重放分量、前一账本hash；从来源逐步重算，比较分类累计与完整读写集合，不信任自报数值或最终文档替换。 |
| 草稿状态与采用凭证 | 草稿revision/contentHash之外，另绑定策略hash、来源hash及当前账本头/预算状态hash；检查、预演采用、claim/lease和本机确认都核对同一组身份。工程内容hash继续只表示完整工程内容，不用相同内容hash推断相同预算状态。 |
| 执行消耗检查点 | 实际执行端将累计请求/工具、时间、工作及制品消耗绑定流程/任务/代次和账本头，暂停、失败、重启不清零。运行耗时和provider实际用量不要求确定性重放得到同值，也不混入工程内容hash；渠道缺失或在途结果不明继续标未知。 |

接续顺序为：校验协议与冻结策略→从完整来源重放并在本机校验真实资源/完整projectHash→确认原主工程基线及草稿身份→以保留`G`、`A=0`的初始分类状态创建首次AI修改账本→逐步累计并在最终采用前完整复核。只有第一次进入AI段时`A=0`；恢复、继续及重连从已保存累计值开始。服务端不能把浏览器自报耗时或回执当作放宽自身执行额度的证明；跨端成本须重放，执行余量须来自可验证的执行记录，缺证明时拒绝接续并保留合法成果。

用户等待/暂停不占主动执行时间，任务到期仍独立生效；运行中的生成、校验、排队/冷却、网络与模型等待计入执行时钟。取消终止当前代次，已发送计费请求的未知状态不得自动重发。相同任务/操作的重放或交付不重复安装和扣逻辑编辑量，重复执行实际发生的计算、工具尝试和时间仍受执行保护。

**版本与恢复：** 新创作载荷族以显式schemaVersion=2承载策略、来源与分类账本，相关状态、摘要、草稿戳及采用凭证一起分派；底图协议使用`sceneweave-base-map@2`，请求和结果指纹覆盖新策略及成本字段。外层HTTP路由`/v1`与载荷版本不是同一维度，必须先协商能力再发送新载荷；旧端明确拒绝，不剥字段降级。既有@1结果hash、创作v1累计公式和旧任务检查点保持原义，不能补字段后冒充v2来源。

新账本属于任务服务/本机流程状态，按原授权、任务保留期和磁盘保护保存，不塞入当前严格工程或默认导出。冷读只有工程文件、缺少完整流程来源/账本/执行检查点时，工程仍可独立打开编辑，但不能声称恢复原流程额度；另建基于现有工程的授权任务须明确作为新任务，不能由重连或失败处理自动创建来重置额度。具体计时分布与限额由后续诊断确定。

## 3. 技能与工具

技能是可版本化的工作说明：目标、适用情形、步骤、示例和检查标准，例如俯视素材制作、建筑布景、墓园风格或渐进同化。由项目维护，任务记录技能标识/版本。模型可选择适用技能，技能不能增加权限；素材名称、导入文字和用户内容不能伪装成系统指令。Codex 本机已安装的技能不会自动接入应用。

工具是有严格参数和返回值的真实 API。任务服务向模型声明本次可用子集，拼装完整调用参数后解析、执行，将成功或结构化失败结果返回模型再继续。流式输出只负责显示和传输，不直接写主工程；不执行半段 JSON，不接受任意 JSON Patch 或整份模型文档替换。

| 工具组（精确schema见共享AI模块） | 允许的能力 | 边界 |
|---|---|---|
| 场景/目录读取 | 场景摘要、明确对象/范围、固定素材检索、尺寸/来源/许可 | 只读上下文不自动成为可写范围；不读用户全盘或未选个人库 |
| 放置/调整/参数 | 独立物件、组合成员、已有有限外观参数 | 固定定义、显式支撑、完整依赖/锁；同化不改布局或物理语义 |
| 建筑/室外 | 逐步接入已支持的绘房/共墙/附着门窗、地形/道路/连接/散布命令 | 几何工具返回真实实体和完整依赖；图片不证明通行；不开放未验证的任意拓扑重写 |
| SVG 制作/派生 | 创建或修改受限静态 SVG，规范化并生成固定位图候选 | 保留原件、实际源/派生字节与许可；不运行脚本或远端资源 |
| 预览/诊断 | 校验草稿、渲染指定受众/范围、返回摘要与可用截图 | 截图外发另按上下文授权；视觉模型支持须实测，失败不能伪称“已看图” |
| 快照/交付 | 请求草稿检查点、准备采用差异、准备本地导出 | 模型不直接采用主工程、不代用户下载或公开；历史局部恢复仅用已实现策略 |
| GM 文字 | 新建绑定对象/位置的GM注记，继续修改本任务新建GM文字 | 已公开文字的改写新建GM草稿并绑定原注记，原公开正文不变；现存GM正文不外发，不自动公开、揭示秘密或解锁 |

当前开放下列有限场景和SVG工具。独立物件删除仍须单独授权并通过依赖检查；不开放建筑/室外任意删除、全场替换或修改编辑锁/可见性。技能、素材文字和成功的上一操作都不能扩大后续权限。

## 4. 任务、流式事件与暂停

创建任务固定 `taskId`、协议/技能版本、主工程身份与基线、范围和允许工具、上下文受众、资产固定版本、预算。服务端草稿有独立 `draftRevision`；它不是主工程 revision。工具调用绑定 task、step/call ID、执行代次和预期草稿版本，重复结果只消费一次。

首版采用 HTTPS 请求与 SSE 事件流，浏览器以 fetch 流读取以携带鉴权头；任务创建、补充要求、暂停/取消和查询通过受控请求。事件至少区分文字增量、工具开始/结果、草稿更新、状态、用量和错误，带单调事件序号。断流后从确认序号恢复；缺口先取完整检查点，不用半份增量拼主工程。精确路由/字段见下文连接协议。

状态语义：准备→运行→等待浏览器/等待补充或暂停→检查→可采用；失败、取消、已采用和基线过期分别展示。用户打断先中止当前执行代次，保留最后有效草稿；追加指令后新代次继续。取消后不自动重开任务，迟到的模型/浏览器结果丢弃。

SQLite 与制品目录保存任务元信息、必要上下文/对话、步骤和检查点，供重连或显式继续；日志只记录脱敏的状态/耗时/用量。保留期、删除、磁盘预算和过期策略按连接协议固定并展示，不能无限积累。任务正文访问受任务归属保护，默认不作为调试日志或工程附件。

浏览器断线不是取消所有服务端计算，也不保证任务能完全继续。需要浏览器渲染、解码或资源时进入等待；重连校验身份后继续。服务重启从已确认检查点恢复为可查询/暂停状态；未知是否已经完成的付费请求不自动重发。

## 5. 草稿、最终采用与局部恢复

服务端只持有用户授权的任务工作副本；主工程留在浏览器。步骤先通过范围/锁/几何/依赖和资源验证，再形成草稿的新完整状态。前端清楚标出“AI草稿”，可查看当前主工程和差异；任务执行期间不制造主工程撤销记录，也不逐个物件要求确认。

最终采用由用户触发：验证任务/草稿来源和完整差异→核对当前主工程基线、读写集合和资源→保存保护点→重新核对源/场景/元数据CAS→一次原子采用，主工程 revision 加一，并有一个撤销单位。保存/保护失败按06保留内存、持久分支和成果，不显示假成功。

等待期间的手工编辑、撤销/重做、重开、切工程使旧基线采用失效。保留草稿供查看或导出为独立成果；重新采用须在新基线上重建候选并复验。首版不自动三方合并，也不把旧AI整体文档覆盖回来。

现行最终事务最多256条实际展开命令，成员/依赖计入同一预算；草稿多轮执行不能绕过最终采用上限。超限要求缩小范围或明确划分下一独立批次，不能用自动拆提交伪装“一次采用”。部分采用须重算完整依赖组、整体校验后再显示可采用，不能删掉失败依赖来凑成功。分类额度及新的语义/计算预算实施前，本段现行规则保持。

采用后的结果沿用既有撤销、命名快照和适用局部恢复。恢复生成当前文档的新事务，保留范围外新编辑；范围、锁、实际资源、保护点与CAS继续检查。现有建筑结构仍受会话连续性限制，现存室外实体受出生/拓扑身份限制；当前完整工程也不自动提供持久建筑或任意拓扑恢复。

## 6. 场景与几何规则

模型提出用途、布局和素材意图；程序以整数毫米和受支持命令生成可编辑实体。共墙唯一，门窗引用稳定端点/真实墙段，支撑表面显式，依赖闭包包含邻室/开口/物件/注记，越出授权范围即失败。硬约束来源由应用保留，模型不得降低尺寸、移除入口或改成软约束。

手工草稿可以暂未连通；AI任务声明完成的普通必达房间必须满足真实入口的结构连通。明确隔离要有用户需求依据，不能将 required 改成 unspecified 来通过检查。门锁、编辑锁、结构连通、当前通行和家具净空分别验证；当前有限净空检查不冒充全图寻路。BSP、A*或通用布局求解器按实际需要另定，不要求先造完整生成器才能接入现有领域工具。

新场景任务使用新/空草稿；已有场景按明确选区及依赖修改，不能由“生成场景”推定允许替换全部已有内容。秘密几何、公开关系和遮罩由核心检查，新GM内容不能先创建成公开再期待秘密门遮住。通用连续高程、城镇路网、任意复杂结构重生成尚无承诺。

## 7. SVG、素材与渐进风格

SVG是可编辑素材源，不是场景物理模型。当前`sceneweave-static-svg v1`只接受svg/g、基本几何/path及defs内受限线性/径向渐变和stop；引用只能指向该源内已定义的渐变。拒绝DOCTYPE/实体、脚本、事件属性、foreignObject、文本/图片、外部URL/字体/CSS、动画、滤镜及其他未支持元素。解析规范化后经独立Blob/Canvas本地栅格化，不把模型SVG插入应用DOM执行。

源与规范化UTF-8各≤1MiB、4096节点、32层、16384属性、256条path、16384条path命令、32768坐标点，坐标绝对值和viewBox边长≤8192。通用本地栅格端口另限边长4096、1600万像素和PNG 20MiB；AI工具的`longEdgePx`进一步限16–1024。工程总字节/像素/来源链及256展开预算取更严限制，这些保护值不作为美术质量或大容量承诺。

源SVG、规范化内容、固定派生PNG、hash、处理器版本、来源/许可及物理标定一起保存，实际像素与源对应。旧默认源和用户固定版本不原地覆写。源→派生→采用均有界校验，工程和完整素材库备份要可离线重开；只存prompt/seed/远端URL不算完成。

同化按单件确认风格→一个组合逐成员→明确多个组合/选区/图层推进。每次扩围冻结新的目标ID、风格基线、允许字段、排除项和预算；不沿同定义/同标签/邻接关系传播，不影响后来入层对象。只读层选区与持续图层外观规则分开。

外观任务保留成员身份、位置、占地、支撑、通行、编辑锁、秘密、人工移动/删除/排除和未选覆盖。不能把组合烘焙成单张图冒充可编辑组合，不能因换图推断碰撞或尺度。新素材物理尺寸/锚点/占地须明确标定并审阅；既有实例外观派生默认沿用既有物理值。

入库和采用是不同事务：用户可只保存固定素材，或在确认后应用到场景；任务中产生的临时资源先归草稿，未采用前不修改共享默认目录。失败/取消后按任务保留期处理临时资源，不能回收工程或快照仍引用的字节。

## 8. 隐私与来源

发起时展示发送给自有服务器和转发给provider的内容范围，两层边界分别核对。服务端可能需要完整工作副本做校验，模型只收本次必要且已授权的上下文；不能将“后端持有”当作“可以向模型全部发送”。默认不发GM秘密、无关库或历史；确需GM上下文由用户明确选择，GM表示对玩家保密，并不自动代表允许外发。

公共素材候选只用许可允许且公开的参考。私密布局/文字可能进入SVG内容或像素，清除元数据不够；受私密来源影响的结果保持相应限制，不自动成为公共素材或玩家输出。公开文字改写先存GM草稿。玩家图继续先过滤内容再派生/渲染，不带源SVG、对话、任务ID、私密名称或生成来源元数据。

名称、标签、注记、导入源和模型说明均是数据，不增加工具权限。模型输出用纯文本/受限Markdown显示，不执行HTML或自动加载外链。许可核对包括参考外发、派生、嵌入和分发条件，未知不能标为允许；模型自述版权不构成依据。

采用成果只记录必要的工具/model、技能版本、源引用、日期和处理摘要；完整对话/任务上下文留任务存储，工程不带隐藏推理、凭据或本地私密路径。任务存储生命周期和日志脱敏均需实测。

## 11. 连接、状态与预算

精确schema位于[共享协议](../src/shared/ai/protocol.ts)和[创作协议](../src/shared/ai/authoring-protocol.ts)，服务路由位于[app.ts](../services/ai/app.ts)。协议schemaVersion=1，未知字段拒绝；能力接口按实际配置报告文字/视觉模型、任务思考设置、sceneDraft/SVG及vision状态，不能从模型名称推断支持。

浏览器只提供后端origin与应用Bearer凭据，凭据仅保留内存；模型、provider endpoint及供应商密钥由服务端固定。Origin按协议/主机/端口精确匹配，不含Pages路径；无Origin的CLI仍须鉴权，null及非白名单Origin拒绝，CORS不替代owner检查。普通对话只发送文字和可选公开sceneId/revision绑定，不自动上传地图、素材或历史；创作元数据与截图各需单独披露授权。

| 路由 | 输入/结果及语义 |
|---|---|
| GET `/healthz` | 仅存活信息，不泄配置 |
| GET `/v1/capabilities` | 鉴权后返回模型、协议、能力状态和预算 |
| POST `/v1/tasks` | UUID clientRequestId、prompt、context及可选创作/截图/思考程度；同owner、同ID、同请求幂等复用，内容不同409 |
| GET `/v1/tasks?sceneId=…`、GET `/v1/tasks/:id` | 仅本owner任务；列表最多20，快照包含全文、工具结果、代次、序号、用量、过期及可选草稿摘要 |
| GET `/v1/tasks/:id/events?after=N` | fetch＋Bearer读取SSE，event=task、id=sequence；重复忽略，缺口/超前游标先查完整快照；断订阅不等于取消 |
| POST `/v1/tasks/:id/control` | expectedGeneration及pause/cancel/resume，可附继续文字/截图；中止旧执行代次，resume须用户明确触发 |
| 草稿检查、claim、release、applied端点 | 按确切代次、draftRevision/contentHash和采用租约完成本机校验及结果确认；不能写主工程 |
| DELETE `/v1/tasks/:id` | 删除本owner服务任务及私有制品，不删除本机工程、历史或已采用字节 |

统一错误为`{schemaVersion:1,error:{code,message,retryable,requestState}}`；requestState区分not_sent/unknown/finished。错误只返安全固定文案，不回显provider正文/请求头/凭据。事件区分text_delta、tool_started、tool_result、draft_updated、status、usage、error，均带taskId/sequence/generation；半段JSON不能执行工具。

当前任务状态为running、paused、completed、cancelled、failed、expired、waiting_browser、ready、applying、applied。completed只表示普通对话结束；创作必须经本机重放与实际资源校验才ready，采用结果由本机确认applied。SQLite保存私有对话、完整事件及检查点；重启将running保全为paused，提示在途计费未知，不自动重发。断流最多3次自动重连事件订阅，耗尽后由用户重连，不能借重连新建模型请求。

| 保护项 | 普通对话 | 创作草稿 |
|---|---|---|
| 输入/输出 | 每次文字16KiB、HTTP32KiB、累计可见输出64KiB | 同文字/输出限额；元数据4MiB、创建请求5MiB；带图请求另按截图6MiB限额 |
| 请求/工具/时间 | 累计4次模型请求、8次工具、120秒 | 累计16次模型请求、64次工具、300秒；每步最多16操作、累计实际展开256 |
| 每次输出token参数 | 1024 | 默认1024，服务端可显式设1–8192；不是费用上限 |
| 事件/回执 | 2048条任务事件；完整工具回执≤8KiB | 同任务保护；增加输出预算只放宽provider SSE解码至4MiB/16384事件，不放宽任务输出和回执 |
| 生命周期/磁盘 | 创建起7日、每任务16MiB、服务256MiB/最多256任务 | 同一累计限制，SVG及私有续答数据均计入 |

每owner/工程至多一个运行或暂停任务，服务默认最多4个并行执行。DB/journal/制品计入实际磁盘检查；SQLite文件0600、私有目录0700。用量按渠道实际返回记录，缺失为未知，不记零；不自动模型重试，不以max_tokens承诺价格。普通provider流≤1024输出预算使用1MiB/2048事件；单行32KiB、单事件64KiB、工具参数8KiB、可见输出64KiB始终保持。清理只处理服务私有任务数据，不开放任意路径/URL抓取。

## 12. 授权基线、独立草稿与采用

固定应用技能为`sceneweave-prop-authoring v1`、`sceneweave-scene-authoring v1`和`sceneweave-artwork-authoring v1`；不读取本机Codex技能。技能只缩小权限，允许工具由当前严格授权冻结。

开始前，用户在产品中明确冻结现存目标ID、操作种类；如允许新增，还须指定Floor/图层、公开支撑面、导出范围及允许的固定物件定义。界面单独征得完整元数据发送许可：自有后端接收完整`ProjectData`（可能含主持人字段）以运行纯规则，不接收位图字节或历史快照；模型仅接收公开授权摘要/目标、必要支撑形状和授权素材名称、标签、尺寸。标题、秘密内容、无关对象和许可正文不进模型上下文。素材名称和标签始终视为数据。

后端持久保存起始元数据和成功步骤账本，不改本机主工程。新对象/出生token/外观覆盖ID由固定seed、准备时间、步骤和计数器确定；草稿独立`draftRevision`增加，主文档revision/更新时间保持基线。每工具步骤最多16操作，累计实际展开最多256；重复和no-op也计入，失败整步丢弃。不能按事务拆分绕过预算。完整本机校验继续包含真实图片字节、解码及派生像素，服务器`valid`和模型JSON不能充当资源证明。

浏览器使用自身拥有的不可变基线与资源逐步重放，逐字段比较内容hash、成本、读写集合和账本，再生成真正差异。读依赖包含资源/许可/支撑/外观源和排序引用，不因此获得编辑权限；实体、层和真实支撑几何锁仍检查。主工程改变、重开或切换后，旧授权不能直接采用；明确重新绑定仅允许确切相同完整内容，其他情形须基于当前工程创建新任务。旧草稿可查询；本机仍持有授权基线和完整资源时可下载独立备份。刷新后必须重新绑定确切基线，当前工程已改变时拒绝重绑，服务端没有图片字节可代替旧工程备份。不做自动三方合并。

创作预算见[连接协议](#11-连接状态与预算)。模型结束先进入`waiting_browser`并停执行时钟，本机重放及真实资源校验通过确切头后进入`ready`。浏览器关闭时不承诺后台完成真实像素校验；刷新/重连只读取检查点，不自动继续付费请求。

最终采用先完整验证并保存当前工程、同metadata CAS建立保护快照，然后申请确切代次/草稿hash的30秒采用租约。`applying`期间后端拒绝暂停、取消、删除；本机关键期阻止其他写事务。保守按本地请求起点扣除耗时，复查保护与持久基线后，一次revision+1、一个撤销单位。最终保存同一IndexedDB写事务同时检查原revision、metadata版本和保护ID/hash。内存提交与保存结果分开：保存失败保留新内存/撤销、保护和旧持久分支，不假报成功。

采用回执只确认本机结果，服务器不写主工程。同claim重试不延长租约；到期/重启转暂停并保留claim，可补认已在有效期内完成的同一回执。未解决claim禁止继续模型；明确释放撤销该claim并使迟到回执失效。界面采用结果未知时只能核对/补发回执，不再次提交同一候选。暂停/继续保留最后有效账本和累计预算，取消及代次变化使迟到模型结果失效。暂停后也可明确“结束生成并审阅当前草稿”，本机重放/资源验证及确切头校验后直接ready，不再调用模型；未解决claim不能经此入口跳过核对。

历史单元、浏览器、真实模型和首轮失败见[AI历史](archive/ai-validation.md)；受控故障与真实配额/崩溃证据分别记录，不把本节合同当作已验收。

## 13. 场景创作工具

固定技能`sceneweave-scene-authoring v1`及`sceneweave_edit_scene`，与既有`read_scene`、`find_assets`、`edit_props`、`check_draft`共用严格账本。用户分别冻结Floor、用户图层、整数毫米矩形、现存公开实体及其真实依赖、固定物件/组合/材质版本和操作种类。界面列出选中结构的依赖供授权；不能把只读依赖或成功新建一间房推导为全工程授权。新内容只写授权图层，本任务生成的实体ID可供后续步骤使用，地理范围、素材定义和操作许可不随之扩大。

| 有限操作 | 当前实际行为 |
|---|---|
| `room`、`wall`、`vertex`、`opening`、`entrance` | 绘制可编辑房间并复用真实共墙；调墙厚/顶点；按墙稳定端点和沿墙距离加门窗；设置真实入口。`wall.materialId`已支持，可只换明确授权墙面材质 |

| `prefab`、`furnish` | 放置固定版本组合及可编辑成员，或在显式Floor/房间/地形上布置独立家具；新独立家具可继续使用已授权的移动/旋转/透明度及单独授权删除 |
| `scatter`、`scatterRegenerate` | 对明确区域/道路/边带生成并保存真实成员，再生成保留人工移动、删除和排除记录；不以seed替代存档 |
| `gmNote`、`gmNoteUpdate` | 新建绑定位置或授权对象的GM文字，并继续改写本任务新建的GM注记；改写既有公开文字时必须另建GM注记并锚定原注记，保留公开原文。既有GM正文不进入授权/模型上下文 |

服务端与本机均复用现有建筑/室外预览和原子命令。核对实际共享房间、邻墙转角、开口、支撑、组合/散布成员及递归注记；跨Floor、未授权依赖、实体/图层锁、玩家遮罩和真实图像/占地/墙带越界都拒绝整步。预览与重放使用确切生成ID，地形边点/段、组合/散布成员/排除及约束变动计入展开成本，与其他场景、物件和素材步骤共用累计256预算；重复/no-op至少计1。通用独立物件工具不隐式取得组合/散布成员或带注记/路径依赖的编辑权。

工具失败返回有限类别和修正方向；原生诊断中未授权私密对象的ID/内容被过滤。模型可在原范围、剩余轮数/时间/预算内修正；失败不推进账本或修改主工程。读回场景得到真实墙、顶点、边段和成员ID，草稿由原生Canvas呈现及差异表审阅；没有模型截图回看/视觉输入通过的声明。最终仍按第12节保护点、确切基线/资源重放、30秒租约和同事务CAS一次采用；不添加通用寻路、全局布局求解、建筑持久恢复或任意拓扑恢复。

## 14. SVG与渐进同化的执行合同

`sceneweave-artwork-authoring v1`，工具只接受`svg`和`style`配方；`style`字段限`tint`、`brightness`、`opacity`。授权模式为单件、一个固定组合的存活成员、明确矩形内冻结的所选物件；也可明确包含本任务新增物件。范围内全选是发起前形成的固定ID集合，不是持续传播规则；后加对象、同定义/同标签对象和未选区域不自动跟随。既有图层覆盖继续保留，换图不改变位置、视觉毫米范围、占地、支撑、通行、秘密或锁。

`svg`仅为授权物件制作新的固定外观版本，原定义、原图及祖先源保全；没有无原件/许可的任意新素材入口。服务端先严格解析/规范化，将源与规范化文本写入0700私有任务目录，0600文件经完整重读后原子发布；不提供任意路径/URL或SVG执行端点。浏览器从已拥有的基线与账本独立生成实际PNG，校验源/规范化SHA、尺寸、解码、实际栅格像素及处理器`sceneweave-static-svg v1`，再建立新资产/定义/父源和确切许可绑定。调色/亮度使用实际位图派生，符号须先制作SVG；透明度不改变物理字段。来源链、许可、私密支撑和真实资源验证不能由服务器摘要代替。

当前服务声明`svg:true`表示工具链可用，实际栅格在本机；视觉是否启用仍服从实际连接能力和独立实测。任务的源/规范化文本属于私有暂存，采用后的完整源与PNG属于本机工程资源。当前、所选命名/保护历史、普通/历史ZIP和冷IndexedDB均携带真实源闭包；SVG个人库使用算法2中性载体/备份，无SVG算法1固定身份保持。入库继续由用户走普通目录事务，不由模型暗改默认库；删除/过期任务不能删除已采用工程或快照资源。

配方与场景操作累计≤256；SVG预留每次9项、风格按目标及实际派生/覆盖类别计费，重复操作也占用。浏览器仅在完整资源/像素校验后生成候选，取消、缺源、坏hash、编码/解码失败不产生可采用的部分成果。最终保护采用、撤销/重做、保存失败、旧基线拒绝沿用第12节。采用后适用的独立物件/组合外观恢复仍先保护当前、保全真实祖先源并保持范围外后续修改；没有扩展建筑或任意拓扑恢复。

SVG实际源/像素、冷存储和目录历史证据见[AI历史](archive/ai-validation.md)；采用后仍按当前资源闭包及有限恢复合同验证。

### 18.4 有限构图候选与回执原子性

[有限构图候选](../src/shared/ai/composition-candidates.ts)：layout覆盖海岸/岩岛/室内，使用明确前缀、授权材质及有限变体；室内由真实原生房间候选取得墙ID后创建门树/入口。furnishing接受1–6个固定定义、每次1–8件，交替变体并核对真实旋转图像/占地、冻结支撑、保留区及门/台阶净空。style把配色/纹理尺度映射到实际边带、素材与tileSize，光向仅在另行授权全Floor环境时可写；不支持的位图线宽修改明确列unsupported。

三个候选均在完整`applyAuthoringStep`账本中预演，不安装步骤、不扣展开操作，仍消耗工具请求。返回确切累计成本和预留量；完整几何/支撑/锁/玩家投影/资源约束不因只读而省略。授权外或私密依赖失败安全拒绝，回执不发送其ID、位置或数量，也不借候选自动增加权限。256累计含重复和no-op，不自动拆批；模型实际选择后仍调用普通编辑，采用时本机再次确切重放。

服务回执的模型/工具/时间剩余额度读取任务真实`store.limits`，不把默认16/64额度写死到较窄任务。最后一个authoring请求发送`tools:[]`，要求文字列出已完成、缺项及未验证内容；若渠道仍返回工具，先持久化该已完成请求的usage，再以`failed/request_limit/requestState:finished`结束，不执行这些工具、不改已有草稿、不自动重发。正常最终文字后有合法delta才进入`waiting_browser`，它不代表主工程已采用、完整需求或美术已通过。

回执原子性要求：所有安装延迟到完整包装后≤8192字节才执行，包装后超限整步无写入。完整依赖验证仅回固定说明，不返回全工程依赖数量；范围外GM manualMask数量不同，模型可见回执仍相同。受控测试不替代真实独立任务验收，历史回执故障与验证见[视觉历史](archive/visual-quality-validation.md#doc-54-12-q3有限候选实际预算与失败原子性2026-10-26)。

### 18.5 模型路由、输出预算与私有续答

新增服务端`SCENEWEAVE_AI_AUTHORING_OUTPUT_TOKENS`：默认1024、显式允许1–8192，只用于authoring；普通对话仍1024。连接能力可显示该创作预算。图片探针仍默认128，可用`--probe-max-output-tokens`显式设1–8192并记录实际值。两者都不是渠道费用承诺；输出字节65536、工具参数/完整回执8KiB、16请求/64工具/300秒及256累计展开等原保护不变。


SSE解码保护：普通≤1024输出预算使用1MiB/2048事件，较高创作预算使用4MiB/16384事件；单行32KiB、单事件64KiB、工具参数8KiB、可见输出64KiB和任务操作保护保持。实际探针与回归结果见[AI历史台账](archive/ai-validation.md#doc-05-provider-results)。

官方[思考模式说明](https://docs.bigmodel.cn/cn/guide/capabilities/thinking-mode)明确GLM-5.3/FLASH强制思考，工具续答须保留`reasoning_content`。新增默认disabled的`SCENEWEAVE_AI_PROVIDER_PRESERVE_REASONING=enabled|disabled`；本渠道私有配置显式enabled。启用时只把它作为不透明provider续答数据保留于私有消息，每回复最多64KiB，计入原每任务16MiB/全库256MiB与七日生命周期；不解释或执行，不进入文字回调、snapshot/SSE、工具回执或工程/导出。关闭后不再保存或发给provider，既有任务在下次请求时剥离该任务历史字段，不批量重写全部旧任务。官方说明与本地边界测试均不能替代真实创作验收。

provider组合schema显式提供根`type:object`、分支属性并集、`required:[kind]`及`additionalProperties:false`，保留严格`oneOf`和运行时`CompositionCandidateSchema.parse`；不补默认值或扩大授权。根schema兼容处理不证明历史失败的唯一原因，也不替代真实创作复验。

### 18.6 工具参数与有限诊断

以下工具约定不扩大任务预算或授权，错误参数严格拒绝：

- `find_assets`按最终完整工具回执裁页，计入`callId/name`、嵌套JSON转义、剩余预算和最终轮提示。条目完整返回，`nextOffset`按实际数量推进；单条仍超8KiB时拒绝，不截断定义。最终回执硬门及拒绝前不安装草稿/计划/制品的规则保持。
- `plan_draft.requirements[].index`只索引冻结的`brief.requirements`，从0开始；`checks/evidenceChecks`是独立诊断列表。无brief、越界、重复索引和claimed缺证据返回`invalid_arguments`及固定修正提示；未授权证据返回`outside_scope`，不回显其ID。失败保留原计划、摘要和草稿。
- 曲线提案明确用`{"operations":[candidateOperation]}`提交编辑，组合提案用`{"operations":candidateOperations}`；操作字段直接位于数组元素顶层，不新增`candidateOperation/boundary`包装或null可选字段。回执、工具说明与制作指导一致；错误输入继续严格拒绝，不自动解包。
- 布局材质角色写入schema说明和候选details：海岸base水/primary沙；岩岛base水/primary低台/secondary高台；室内primary普通地板，secondary覆盖厨房地板，缺secondary时厨房回退primary，base不使用。墙材质仍需单独显式操作，缺材质继续报告未完成。

对应失败与修复见[视觉历史](archive/visual-quality-validation.md#doc-54-136-2026-10-28-q4失败后的有限修复)，完整Q4仍待新冻结真实验收。

<a id="1913-曲线候选的短参数采用"></a>
### 18.7 曲线候选的短参数采用

只读曲线提案同时提供完整`candidateOperation`和短`candidateRecipe:{proposal,candidateHash}`。`candidateHash`是普通曲线操作规范JSON的SHA256，配方用于确定性重算，不授予新权限，也不充当持久候选回执。`sceneweave_apply_boundary_candidates`严格接收确切`atDraftRevision/atContentHash`与1–2个候选recipe，同批boundaryId不重复；先验证基线，再按既有公开范围重建并逐hash比对，最后一次执行普通曲线事务。基线变化返回`stale_candidate`，操作hash不符返回`invalid_candidate`；其余授权、依赖、锁、真实展开预算和完整回执原子拒绝与普通编辑相同。

优先复制短recipe，避免模型转录整段控制点；需要时仍可通过`edit_scene`提交完整普通操作。没有新增工程/任务持久字段，保存的账本仍是完整`visualBoundary`，本机资源校验、保护/CAS与一次采用不变。单批只读提案的独立成本提示不能相加当作最终可用预算；采用时重新计算整批真实累计展开。历史pilot和短入口验证见[视觉历史](archive/visual-quality-validation.md#doc-54-137-2026-10-28修复后新冻结单份pilot)，确定性验证不关闭Q4。

<a id="1914-按固定授权裁剪工具目录与显式思考强度"></a>
### 18.8 按固定授权裁剪工具目录与显式思考强度

引擎每个非最终工具轮按已验证的固定scope生成模型目录：`edit_scene`分支取顶层、scene、visual和artwork四组operations并集，`edit_props`只取顶层四类中已授权项，空集隐藏对应入口。曲线提案/短参数采用须有`visualBoundary`授权；地形工具只在scene存在对应生成/编辑授权时出现，候选数组精确裁剪，regenerate仅`terrainEdit`、区域下钻仅`regionalEdit`。保留composition严格oneOf与根object兼容层；不按brief、文件名或实体数量推导权限，任务新建对象仍有原先获准的变换能力。

目录逐任务独立复制；执行端完整schema、公开范围、依赖/锁、普通账本、256实际展开、8KiB回执及本机保护/CAS保持。未展示的调用仍由原执行端校验。曲线`areaId`是现存地形，`boundaryId`须是不同于该地形及其他现存实体的新ID。

新增可选`SCENEWEAVE_AI_PROVIDER_REASONING_EFFORT=low|high|max`，缺省不发送额外字段，显式配置才发送`thinking:{type:'enabled'}`和`reasoning_effort`。provider创建时捕获配置，非法值在请求前安全拒绝。[官方GLM-5.3说明](https://docs.bigmodel.cn/cn/guide/models/text/glm-5.3)规定强制思考、默认max并建议enabled+low；[思考文档](https://docs.bigmodel.cn/cn/guide/capabilities/thinking)确认Coding Plan可用low，当前Flash亦支持。此项不代替私有`reasoning_content`续答，不改变8192输出/16请求/64工具/300秒等原预算；effort不是独立数字预算，不承诺正文余量、固定延迟或费用。配置变化不恢复或重发旧unknown任务。验证和真实结果见[54第13.9–13.10节](archive/visual-quality-validation.md#doc-54-139-2026-10-28短参数入口真实pilot)。

<a id="1915-按剩余时间收尾与锚点参数诊断"></a>
### 18.9 按剩余时间收尾与锚点参数诊断

authoring每轮在可取消的请求排队/冷却结束后，重新读取任务及剩余时间，再选择工具目录、构造payload和增加请求计数。除最后一个允许请求外，剩余时间不超过`min(30000ms, executionMs/10) + requestScheduler.cooldownMs`时进入最后纯文字轮；当前300秒任务和10秒冷却对应40秒收尾窗口。此窗口包含下一次等待的预留，不保证供应商在硬门内返回；硬timer、16请求/64工具/256展开及输出预算保持，不自动重试或采用。

受控runner使用`createControlledTaskRunner`，默认同一实例按响应结束到下次请求等待10000ms，允许0–60000ms；构造/导入不创建、恢复或发送任务。冷却计入原执行时钟，等待期间不增加请求计数，等待超时记`not_sent`，已发且未完成的请求仍记`unknown`；暂停/取消会中止排队。fetch只负责传输，不能再隐藏sleep或重试。生产服务未配置scheduler时不增加冷却，普通对话不使用authoring文字收尾规则。

最终文字轮不发送工具，要求如实说明已完成、未检查/未满足需求及部分草稿。正常完成仍须按原合同校验后进入`waiting_browser`或`completed`，本机资源、保护点、claim/CAS与采用保持独立。供应商忽略禁工具要求时整批不执行，保留完整响应用量，按触发原因记录`execution_limit`或`request_limit / finished`。必要测试、首轮问题及未发新付费请求的边界见[基础修复记录](archive/ai-validation.md#foundation-20261028)。

`read_scene`的`anchors`参数须恰有一个terrain ID；缺失、空或多ID在读取前返回`invalid_arguments`与固定提示，建议分开调用或用`scene`读取多对象摘要，不再误诊为几何错误。有效单对象分页、授权和私密过滤保持。历史unknown任务不因此恢复或重发；结构检查不计为完整AI成功。

<a id="1916-页面选择与任务固定思考程度"></a>
### 18.10 页面选择与任务固定思考程度

“AI对话”在新任务设置中提供跟随服务、low、high和max，并提示“请选择模型支持的思考程度”。普通对话和场景草稿共用选择；选择不是供应商能力探测，不把任意模型名当作支持证明。连接能力新增可选`taskReasoningEffort:true`，同时回显服务默认`reasoningEffort`，未显式设置为null；后端缺少此能力时页面禁用选择并提示更新。

`CreateTaskRequest.reasoningEffort`可省略或为上述三档，null、其他字符串及任意值仍严格拒绝。创建事务把显式请求值或创建时服务默认原子写入任务快照`reasoningEffort`；null表示保持模型自身默认、供应商请求不发`thinking/reasoning_effort`，不等于关闭思考。原请求指纹仍基于客户端完整payload：相同请求ID与原payload只读返回原任务，改变程度产生幂等冲突；不能通过重试改设置。`ControlTaskRequest`不接收此字段，暂停/继续/重启保留原有效值；既有缺字段任务不批量改写。当前任务单独回显固定设置，页面更改仅作用于下一新任务。

引擎每轮将快照程度传入provider；任务显式档位覆盖服务捕获值，null显式抑制服务回退，旧任务undefined保留既有provider行为。直接provider非法参数在fetch前安全拒绝，配置和请求不相互修改，并发任务独立。视觉模型路由、私有思考续答、请求/输出/时间/展开预算及保护采用不变。设置只属于任务服务和页面内存，不进入SceneDocument、工程、历史或导出；创建结果未知时页面重试使用原payload和ID。验证与真实超时边界见[54第13.13节](archive/visual-quality-validation.md#doc-54-1313-页面思考程度与超时时间线)。

## 19. 地形AI的当前能力与剩余边界

手工生成在浏览器短生命周期Worker调用共享纯核心，主机完整重放并校验几何、真实资源、成本与基线后才可采用；完整结果、规则、人工记录和来源一起保存，seed/预览图不作为唯一工程。尺寸、组合路径及拒绝边界见[地形设计](reference/terrain-generation.md)。

| 严格工程 | 已实现的有限AI写入 | 边界 |
|---|---|---|
| 完整v3 | `terrainGenerate`、`terrainEdit`、`regionalGenerate`、`regionalEdit` | 场景生成须为空、匹配sceneId并覆盖确切授权范围；编辑固定floor/scope/材质；区域下钻独立候选且仅获准公开子集 |
| 完整v4 | `terrainLocal` | 对现有组合文档做授权内局部刷新；不把v3生成请求直接送进v4或剥字段回退 |

候选绑定草稿revision/contentHash与冻结授权。只读准备可形成最多三个独立候选、局部制品/诊断或独立下钻候选；准备不写草稿，应用仅进入隔离账本。隐藏、来源和只读依赖不自动获准，生成图层/区域符号另行授权。本机最终重放、真实资源与许可闭包、256累计成本、8KiB回执、保护点/CAS和一次采用均保持。

这些协议和有限入口已实现；真实模型16项自然语言任务及4项局部修改、跨模型稳定性、视觉和P3仍未验收。无模型的程序底图HTTP/Worker链路已接通；“AI在确切物化结果上修改”、生成/AI分类额度及完整初始账本承接仍是[开发整改任务](07-roadmap.md#development)，不能因底图接口或地形工具已接入而标记整项完成。未知计费请求不自动重发。

新工具调用的岩岛/海岸生成缺省在候选身份和步骤hash固定前显式选择`terrain-scene@2`；显式1保留，旧候选采用与旧账本重放不补写版本。新算法不扩大授权：海岸边缘效果完整宽度越出有限scope时仍拒绝，不能把这一入口接入视为海岸AI真实旅程已通过。版本与完整输出语义见[04](04-scene-document.md)。
