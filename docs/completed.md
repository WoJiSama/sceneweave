# 已完成功能

这里集中记录已经实现的能力和普通入口。实现完成不等于所有设备、视觉效果或外部软件都已验证；具体未解决问题只放在[剩余事项](roadmap.md)。不再逐次追加开发经过、测试计数或批次编号。

<a id="editing"></a>
## 场景编辑

| 能力 | 可以做什么 / 从哪里用 |
|---|---|
| 统一工作台 | 在场景、生成、地形、建筑、素材与布景、氛围之间切换；AI和历史提供独立入口 |
| 建筑 | 绘制及调整房间、共享墙、门窗；支持有限结构修复、组合变换和完整影响预览 |
| 物件 | 查找、放置、移动、旋转、复制、框选和批量编辑；人工锁、物理占地与私密性分别保存 |
| 图层与楼层 | 用户图层排序、隐藏、独显和锁定；多Floor编辑、总览、入口关联与坐标定位 |
| 撤销与历史 | 原子采用、撤销重做、命名快照、分支保全及有限属性恢复 |
| 通路检查 | 显式声明两端、净宽和门状态；相关编辑重新核对实际通行 |
| 注记 | 名称、线索、关联阅读与定位；主持人信息按受众过滤 |

<a id="ocean"></a>
## 静态海洋

海岸和岩岛可追加海面、固定浪纹、舟船和生物布景。物件支持水面、水下及部分出水外观、波纹和静态尾流；船内使用普通Floor、房间和家具编辑。样板提供自然岸带的近岸海战、原尺寸远洋巨怪和三层船图；浅水与岸线共用地形曲线、羽化及材质覆盖，船内共用普通楼层、入口和家具。海洋布景优先安排大尺寸图像，空间不足时明确列出缺项。动态海浪、船体航行及跨层寻路不在当前支持范围。

<a id="assets"></a>
## 素材、布景与图片

| 能力 | 可以做什么 / 从哪里用 |
|---|---|
| 素材发现与导入 | 按名称、年代、风格和用途查找；单图、受限SVG、文件夹或清单ZIP导入 |
| 个人素材库 | 把工程中的固定内容保存为个人素材，独立备份并在另一工程采用 |
| 用途布置 | 按真实房间尺寸、门窗和功能选择家具；多房间分别配置后统一预览、采用与撤销 |
| 场景模板 | 保存当前布景或完整房间/建筑，查找后在目标工程平移或四分之一圈旋转放置 |
| 图片拆解 | 从图片入口标定、粗圈、辅助分割、磁性套索和保留/排除画笔，拆出可编辑item |
| 图片制作接续 | 独立工作包保存选区、来源和制作进度；页面与MCP共用处理链 |
| 素材编辑 | 修改名称、尺寸、占地、来源和图像；有限本机处理、矢量重建及独立模型补画候选 |

## 可选AI与共享工具

已接通流式聊天、受限草稿工具、参数助手，以及林中建筑的有限候选比较和指定房间家具修正。最终工程仍经用户审阅采用。手工编辑可以离线于模型运行；真实制作收益仍需比较。

应用与外部助手共用Git管理的工作流目录，可按步骤查询实际宿主能力、schema、效果与断点。地图CLI可交付完整工程，图片MCP可接续独立制作工作包。普通应用聊天尚无图片执行工具，目录出现某项能力不表示当前宿主已接线。

工作流自带的林中建筑预览及其来源数据保留在[示例数据](../workflows/examples/forest-building-20261117.json)。它只代表该固定输入；家具缺项、视觉签收和模型提效不能由预览存在推定通过。
