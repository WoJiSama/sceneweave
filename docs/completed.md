# 已完成功能

这里集中记录已经实现的能力和普通入口。实现完成不等于所有设备、视觉效果或外部软件都已验证；具体未解决问题只放在[剩余事项](roadmap.md)。不再逐次追加开发经过、测试计数或批次编号。

<a id="editing"></a>
## 场景编辑

| 能力 | 可以做什么 / 从哪里用 |
|---|---|
| 备团首页 | 首次可直接新建手绘场景，打开首页样板、图片导入或参数生成；已有会话可继续编辑。 |
| 首页样板 | 余烬酒馆与旅舍、溪岸巡林补给站、旧墓库和灰脊火口观测步道支持正俯视与 3D 高清预览和可编辑副本。分发的九份示例保存物件立体结构与高度，建筑示例另有墙高、门高和窗台尺寸。酒馆画风对比线可平移，拖动任一端点可连续旋转 360°。按住溪岸地图可环绕并调整俯角。地形和线稿教程可直接打开配套练习副本 |
| 使用教程 | 首页「使用教程」和工作台「操作帮助」均可进入，包含林边驿站制作到交付、斜俯视取景与出图的步骤、分模块索引与实机图示 |
| 首次加载 | 直达教程只加载阅读代码。能确认浏览器尚无当前工程库时，首页直接显示空目录。首页预览进入可视范围时读取。新建表单随首页加载，打开后暂停未完成的预览，并行准备画布、基础地面和默认房间地板。取消新建后，可见预览恢复。空白场景使用同一编辑会话。SVG 栅格化、自动道路规划、自然石阶渲染、楼层工具和候选详情随项目内容或操作加载。常用和内置素材先读取目录，显示缩略图或准备所选编辑时读取图片，采用的图片与许可随工程保存。AI 授权与草稿重放、图片精修的像素重放、林中建筑候选、局部与区域地形制作、海岛布景和场景模板的执行代码随各自操作加载。 |
| 统一工作台 | 在场景、生成、地形、建筑、素材与布景、氛围之间切换，AI 和历史提供独立入口。左栏优先显示当前任务或素材搜索与结果，右栏滚动属性时保留所选对象名称、图层和锁定状态。桌面可交换侧栏停靠并记忆布局，窄屏以图标和单侧抽屉浏览 |
| 界面过渡 | 首页、教程、工作区和新场景打开时使用居中的织境标志显示加载状态。加载动画与工具、侧栏、对话框和首页 3D 过渡均跟随系统的「减少动态效果」设置 |
| 斜俯视取景 | 默认在正俯视编辑，可旋转、缩放、开启地图底座并导出当前镜位的 PNG。导出按快照、受众、楼层、镜位及尺寸独立准备。墙与立体物件按可见范围和地表高度烘焙方向性阴影，投影与俯视崖面的受光共用世界光向。岩壳、切壁、坡面接缝和依附起伏的凿岩石阶进入网格，旧崖面在斜俯视映射到已有岩壁几何。原创木箱和木柜可从原图生成侧面，明确指定的侧面图优先。普通预览适配像素比并按需在 CPU 画布重烘近景贴图，接近像素预算上限的尺寸档合并生成。工作台可切到降低预览分辨率并复用基础贴图的性能模式，选择保存在浏览器。准备和出图可取消，工作台可短时复用同一快照的网格，也可淡出近处树冠 |
| 建筑与物件的立体尺寸 | 手工和 AI 建筑候选写入新建墙与门窗高度，室内和混合布局也为生成的墙和门写入高度。常用内置家具与植被有带默认体积的新固定版本，新生成从对应素材版本取形。新导入的图片物件默认平贴，可在素材副本中设置形状、高度和侧面图并旋转预览，失败时显示原因并可切回平面 |
| 建筑 | 手绘独立房间可在画布完成，选中房间或外墙可沿墙扩建，以拖动、两次点击或输入进深预览共墙。房间详情可继续开门窗、摆放单件或整组家具、按用途布置。物件按完整占地归入房间，跨房移动同步更新已有建筑组，门槛处保留原归属并可手选。完整建筑组和自然组按实际墙体、支撑面及锚点同步后放置的对象，包括沿共墙扩建的房间、地形上的独立建筑、道路、植被和附着注记。跨独立地形组的道路、坡道和共用边缘保留双方支撑。房间详情可查看关联对象，整栋移动保留桌面附着。支持结构修复、组合变换和完整影响预览。拖共墙时门窗仍附在同一面墙，搬离单间时预览墙体拆分和门窗归属 |
| 物件 | 查找、放置、移动、旋转、复制、框选和批量编辑，人工锁、物理占地与私密性分别保存。右侧「立体形状」可为导入图选木箱等结构。木箱模板默认创建可吸附的箱顶，物件放上后随箱子移动。可删选中的单件或整组，组外物件在宿主移除后解除附着 |
| 编辑分区 | 「地形 → 用途 / 危险区域」可绘制同楼层内部互斥的分区。聚焦分区后在原图上编辑，归属随边界更新，支持分区迷雾预览和按区裁切双受众 PNG |
| 视线组件 | 在物件详情绘制该实例的局部遮挡线，并从临时视点查看视野。遮挡组件随宿主移动和旋转，可跨标签页或切换工程后粘贴到同类实例 |
| 图层与楼层 | 用户图层支持排序、隐藏、独显和锁定。多楼层支持总览、入口关联与坐标定位。「场景 → 楼层叠绘」按世界坐标合成最多四层，各层独立计算承托和通行。「场景 → 楼层底图」可导入、更换和清除图片，实际资源与许可随完整工程保存，可撤销 |
| 撤销与历史 | 原子采用、撤销重做、命名快照、分支保全及有限属性恢复；确切未变的已校验工程可复用不可变快照，保留真实修改、身份与资源检查 |
| 通路检查 | 显式声明两端、净宽和门状态，相关编辑重新核对实际通行。地形支撑与通路校验先排除无法影响取样的远处边，仍完整检查相交、接触及净宽范围 |
| 注记 | 名称、线索、关联阅读与定位；主持人信息按受众过滤 |
| 秘密房间 | 房间详情统一选择秘密入口与线索，按必要范围生成遮罩并默认保留相邻公开房间；已有罩可收紧，候选内可调整尺寸及保留模式，完整重检后在实际主持人/玩家图中定位公开遮挡，失败保留输入与上一份候选，再原子采用与撤销。玩家出图将扣除公开房间后的遮罩合并为一次不透明填充，消除相邻拼缝 |

分组预览复用同次命令的锁视图和成员关系，语义变更计量按唯一目标键比较，同一基线的步骤与净差异只计量一次，保留完整依赖、身份、资源及预算检查。候选准备和登记共享同一对已验证不可变工程的预算计量，分组审阅对已校验数据直接核对实际字段，提交时复用完全相同的已校验身份记录。自然组工具按需加载，组员列表展开后渲染。大量对象与地形明细展开后可按页查看。采用候选时，如果已校验的工程内容、素材和显示设置一致，主持人编辑画布可复用已绘制的主画面。

## 保存与输出

| 能力 | 可以做什么 / 从哪里用 |
|---|---|
| 完整工程 | 保存实际实体、固定资源、外观、身份和历史，普通入口使用唯一完整 v1。备份记录写入构建，打开时识别所需读取协议。主持人扩展数据随工程和所选快照原样保存。Pages 发布前回归固定工程、所选历史、分支存档和个人库。导入提交后可复用已验证的完整基线编码。保存时在同一事务内逐字节核对库中已有素材和基线内容块 |
| 本地保存 | IndexedDB自动保存、首页重开、跨标签冲突保全和另存副本；文件入口区分浏览器保存、工程备份与PNG，保存失败时提供恢复操作 |
| 工程备份 | 从文件或导出菜单下载含实际资源与秘密的可编辑`.sceneweave`，也可携带明确选中的历史。完整校验后在后台压缩，文件准备期间可取消。保存失败或冲突时可下载当前页面已采用的编辑，备份导入后可继续编辑和保存 |
| 玩家与主持人PNG | 顶栏分别导出两种地图；支持背景、透明度和逐楼层输出；整图取景随世界范围调整，也可独立裁切 |
| 有限UVTT | 导出预检、墙门灯与单位映射、降级报告；多楼层结构包受限时，可直接下载当前楼层的玩家 PNG |

完整工程备份与逐Floor双受众PNG在导出期间重检工程基线，阻止过期下载。Pages 上传前在 `/sceneweave/` 运行桌面与窄屏的完整编辑旅程及保密回归，检查实际下载的玩家 PNG，以及备份在空白存储中导入后的编辑、保存和重开。

## 生成与地形

| 能力 | 可以做什么 / 从哪里用 |
|---|---|
| 画布与生成 | 新建时铺设可编辑的平地，可直接画房、画路和刷地表。「生成」从中央窗口设定范围，程序生成的场景在画布依次画出轮廓、空间和可用细节，可跳到完整预览。结果可点选查看，加入当前楼层后可一次撤销。左栏提供地形工具，右栏显示所选对象 |
| 室内生成 | 按房间用途和占地生成布局、门和家具，详细设置提供面积、墙厚和邻接关系。厨房与储藏室铺石板，木地板按房间用途和比例调整色调及铺向。生成检查外门与家具使用区的实际通路净宽，优先安排炉台、主备餐台和可到达的柜架，储藏室会尝试沿墙接续收纳家具 |
| 森林与火山 | 「森林与营地」按可用片区加密树群、灌木和草簇，地面自动铺设可编辑的苔地、深浅草甸、细砾及连到活动空地的裸土路肩。入口和活动空地保留完整通行范围。火山在空间允许时生成起伏山坡、破口岩盆和弯曲熔岩。正俯视、斜俯视和承托共用实际高程，进山和下火口路线检查完整净宽 |
| 开放地形塑形 | 绘制轮廓时可指定山丘高度。「地形 → 起伏笔刷」可一笔跨过相邻的高程面，也可调整已有切口周围的岩体顶部。地形各自保留轮廓和基础高程，岩缘和切口接合高度继续固定。固定道路、台阶及承托范围标红，选择「保留承托地形」后预览，整笔可一步采用或撤销。连续填切山路可拆除铺面与踏步并保留切口 |
| 有限混合场景 | 在同一楼层生成一栋林中或火山平台建筑。林中建筑的手动预览、浏览器自动候选和 CLI 共用首生成的苔地、土路与按用途铺装。土路经空地接到实际外门，空间允许时在破口火山内为建筑留出平坦支撑。多间休息室可分别安排炉边桌椅和阅读家具 |
| 默认材质画法 | 新建地图自动对可辨识的原创木、石、草木、泥土、灰泥、金属和织物使用各自笔触，俯视、3D 和输出共用。已有地图可以在「氛围 → 画风」预览和采用 |
| 自然地形 | 多地貌、多seed候选、有限地形笔刷、局部重生成、区域图与独立下钻。默认海岸和岩岛按沙岸、干地与崖脚布置物件，滩石、剥落岩和离岸礁共用一套石形。露岩随高差收窄，坡脚的地表高程向低地缓降，两种视角共用转向岩阶和错落踏面。采用后可从场景对象换石形、在画布调整已绑定的礁石和崖壁轮廓，并编辑岩阶路线、净宽和踏面。本机与服务端共用生成规则。底图生成、地形修改和局部联动都通过会话处理预览、取消及过期，采用时重检当前工程 |
| 底图生成配方 | 「生成设置」可选择默认配方、轻量底图、连续地表与成片植被或高台植被与岩阶过渡。配方决定下次生成的地形和布景。现有地图的画法可在「氛围 → 画风」调整 |
| 道路与高差 | 「地形 → 道路」可沿承托面拖画、切换圆滑、配沿边构件并预览。默认宽度可在局部收窄，指定路段可手调宽度及铺阶。主动开凿时，同一候选展示岩体切口、坡面和沿实际路线铺设的台阶。地形还可设置整面高程、有限局部塑形及高差连接 |
| 自动道路 | 「地形 → 绘制地形 → 道路 → 在画布自动选路」依据坡度、挖填量、承托和障碍选路。路肩占地冲突时可在剩余搜索范围内改道，固定路段继续保留。缓坡、阶梯、平台和挖填断面用于通行及两种视图，路缘随邻接地表和挖填高差露出草、土、积雪或岩层。固定途经点、平台长度及高程可分别编辑和恢复自动，改路线可保留手调外观 |
| 桥梁与沿线构件 | 「地形 → 桥梁」可直接建桥，也可在等宽、无依赖的道路详情选段转桥，接续两端引道。桥体饰面和铺面可分别编辑。拖桥吸附后引道末端可跟随，超出范围时放下前标红。普通桥的桥身带厚度与接触阴影，已链接引道的材质在桥面边缘收口。桥梁及道路支持单侧、双侧镜像和按里程留口，重排保留手改、删除和锁定。工业桥提供连续边梁、定尺寸支座、转角件、桥头搭接及构件照光，梁腹和下层投影可调 |
| 设备管线 | 可在设备实例标记与复制管口。拖动或旋转设备时，已经吸附的管端跟随，超出范围先标红，一次撤销恢复设备、管线和链接 |
| 沿线样式与实体围栏 | 「地形 → 绘制地形」提供 12 种内置俯视构件、可闭合并留出入口的围栏，以及沿线样式维护。可调整外观宽度、实际占地和桥面承托宽度。冷却管会在转角生成接头，在端部和开口生成套筒。沿线灯具可随样式保存照地颜色、半径和强度。沿线样式可从源节发布固定版本，经个人库跨工程采用，也可在当前工程批量换版。改线时保留按里程设置的开口和实际手改 |
| 阶梯工具 | 地形制作可新建，连接详情可编辑；10种构造与11种材质，重复或拉伸续接、旋转与曲线、可移除的局部覆盖。凿岩及毛石台阶按实际高差绘制踏步，并用两端可见承托面收边 |
| 附着与山路 | 有限宿主附着与承托，私密宿主只接受已对玩家隐藏的子物件，解绑保留物件原有可见性；连接详情可预览完整坡体，保留原路线净宽，山径与专用阶梯分别编辑，撤销、保存及重开；自然融合仍有缺口 |
| 外观与氛围 | 固定材质、图层/实例覆盖、地表规则、植被、光影、背景和预设对照。「氛围 → 灯光」提供随窗洞变化的窗光、画布聚光、随路线或独立线段延伸的线光，以及沿房间或地形轮廓发光的面光。物件聚光随宿主移动、旋转和镜像。「氛围 → 环境」可编辑日月光方向、高度和阴影柔度。各光型随工程保存，主持人和玩家 PNG 共用渲染，UVTT 将新增光型烘焙到底图。 |
| 全图画风 | 「氛围 → 画风」的原画、手绘、茶绘和线稿共用曝光、冷暖、色彩浓度、对比度及 RGB 综合和单通道曲线。主题分别保存调色与画法，可单用或叠加，独立开关纸纹、笔触和提线。「两侧画风对比」可独立调两侧、复制调色、移动或旋转分界，并采用任一侧。线稿按原生组件结构绘制岸线、道路、桥头、台阶和高差。导入位图在本机降噪提线，优先保留原图连续的浅轮廓，原图随工程保存。「氛围 → 滤镜」的楼层、区域、图层和对象调色使用同一套曲线，楼层和区域调色在线稿淡化灯雾后仍生效。旧工程保留原配方，可预览升级。采用后可撤销，主持人和玩家 PNG 共用画风 |
| 工业赛博朋克 | 「素材 → 主题素材包 → 工业赛博朋克」提供 9 种材质、19 件原创物件、4 种固定沿线样式和 1 个可拆设备组，可用于空白工程并生成碧脉冷却枢纽和暮港吊运环线。收边沿外露轮廓转弯。「地形 → 实体围栏」的护栏平台可绑定完整轮廓或指定连续边段，按可见宽度和实际占地为桥头、台阶和坡道留口。桥路吸附和道路转桥检查接头的连续同高承托，贴合平台的钢桥按实际轮廓开出通行口，钢梁包边在各桥口过渡到对应梁腹截面。玻璃和百叶立面保留设定并延续至桥下。桥梁构造与道路铺装可分别调整。「氛围 → 铺装」支持沿路线铺板并在转角拼接，同规格的引道在桥头共用铺设基准。钢梁包边可调薄并可调整加劲肋尺寸。建筑立面支持调整窗列、框架和灯色，同一直墙的窗列跨分段连续，墙脚按邻台的实际高差收底。桥侧和立面按其朝向响应楼层光照。门路绑定延续铺装到实际门槛，透空楼梯按踏步绘制。物件照光跟随位置、旋转和镜像，可在「外观与图层调整」编辑发光点、颜色、半径与强度。沿线灯可继承整线参数，也可单独覆盖或关闭 |

<a id="ocean"></a>
## 静态海洋

海岸和岩岛可追加海面、固定浪纹、舟船和生物布景。物件支持水面、水下及部分出水外观、波纹和静态尾流。简单船使用普通物件；船内共用普通Floor、房间、入口和家具，支持逐层编辑与总览。样板提供自然岸带的近岸海战、原尺寸远洋巨怪和三层船图。浅水与岸线共用地形曲线、羽化及材质覆盖。在地形属性的「岸边」里可选择一段或整圈，湿岸、浅水色带和浪线随来源边缘生成，工作台与两种 PNG 导出共用。缺少原生Canvas模糊时，地表遮罩使用有界软件回退。海洋布景优先安排大尺寸图像，候选审阅直接列出水域、已放置布景和空间不足的缺项。动态海浪、船体航行及跨层寻路不在当前支持范围。

## 可选AI与共享工具

通用助手可通过本机 CLI 或 MCP 从少量地貌、端点或房间关系生成可编辑草稿。地形支持保留低地内的凸起、独立铺地表、按指定侧自动布置可走的石阶并给通路预留净宽。草稿可定位检查问题，编辑可独立换画风，交付可核对冷读双视图和普通编辑器重开。 [入口](../CONTRIBUTING.md#local-map-harness)

已接通流式聊天、受限草稿工具、参数助手，以及林中建筑的有限候选比较和指定房间家具修正。最终工程仍经用户审阅采用。手工编辑可以离线于模型运行；真实制作收益仍需比较。

共享制图提示词按入口、活动、服务动线和时段组织布置与照明。可移动灯具使用物件发光，让光随宿主更新。

AI面板分别说明普通文字对话、兼容后端与单独授权的草稿、图片流程查阅及拆件入口；截图复核另行征得同意。 草稿采用后的本地保存和编辑可独立于服务器确认完成，连接中断后可重试同步结果或恢复草稿审阅。

AI面板的林中建筑自动候选在刷新后可离线恢复原需求、完整候选和累计预算，重连原后端后可按原模型请求ID查询并由用户继续，恢复的候选经过工作台审阅和保存。

Codex、应用后端与图片MCP按ID、版本和摘要读取Git管理的同一份工作流正文。图片制作与审核规则归共享定义，地图和图片Skill按宿主实际能力接入。林中建筑MCP可按原需求、预算与已校验候选接续；图片MCP的制作包与完整工程交付回执携带同一流程绑定。普通应用聊天尚无图片执行工具，目录出现某项能力不表示当前宿主已接线。

AI 工具列表、工作流发现与调用共用可用条件，视觉复核会重检截图与当前草稿的绑定。工具失败回执明确下一步，区分修正参数、更新候选、缩小操作和停止。图片 MCP 对同一代次的独立读取最多同时执行两项，草稿写入、检查点保存和工程交付按请求顺序执行。

工作流自带的林中建筑预览及其来源数据保留在[示例数据](../workflows/examples/forest-building-20261117.json)。它只代表该固定输入；家具缺项、视觉签收和模型提效不能由预览存在推定通过。
