# 已完成功能

这里集中记录已经实现的能力和普通入口。实现完成不等于所有设备、视觉效果或外部软件都已验证；具体未解决问题只放在[剩余事项](roadmap.md)。不再逐次追加开发经过、测试计数或批次编号。

## 场景编辑

| 能力 | 可以做什么 / 从哪里用 |
|---|---|
| 备团首页 | 以生成、局部修改和交付为主线，优先继续当前会话，保留工程搜索、导入与样板入口 |
| 使用教程 | 首页「使用教程」和工作台「操作帮助」均可进入，包含林边驿站制作到交付的步骤、分模块索引与实机图示 |
| 统一工作台 | 在场景、生成、地形、建筑、素材与布景、氛围之间切换；AI和历史提供独立入口；窄屏合并面板入口，地图选项按需展开并保留键盘操作 |
| 建筑 | 绘制及调整房间、共享墙、门窗；支持有限结构修复、组合变换和完整影响预览 |
| 物件 | 查找、放置、移动、旋转、复制、框选和批量编辑；人工锁、物理占地与私密性分别保存 |
| 图层与楼层 | 用户图层排序、隐藏、独显和锁定；多Floor编辑、总览、入口关联与坐标定位 |
| 撤销与历史 | 原子采用、撤销重做、命名快照、分支保全及有限属性恢复；确切未变的已校验工程可复用不可变快照，保留真实修改、身份与资源检查 |
| 通路检查 | 显式声明两端、净宽和门状态；相关编辑重新核对实际通行 |
| 注记 | 名称、线索、关联阅读与定位；主持人信息按受众过滤 |

分组预览减少同次命令中的重复锁视图、预算比较和关系查找，保留完整依赖、身份、资源及预算检查。

## 保存与输出

| 能力 | 可以做什么 / 从哪里用 |
|---|---|
| 完整工程 | 保存实际实体、固定资源、外观、身份和历史；普通入口使用唯一完整v1 |
| 本地保存 | IndexedDB自动保存、首页重开、跨标签冲突保全和另存副本；文件入口区分浏览器保存、工程备份与PNG，保存失败时提供恢复操作 |
| 工程备份 | 从文件或导出菜单下载含实际资源与秘密的可编辑`.sceneweave`，提示下载发起及备份后的修改；导入为独立工程后可继续编辑、撤销重做并保存重开，可携带明确选中的历史 |
| 玩家与主持人PNG | 顶栏分别导出两种地图；支持背景、透明度和逐Floor输出 |
| 旧数据迁入 | 独立一次性工具保全旧工程、历史和个人素材，验证目标后才切换 |
| 有限UVTT | 导出预检、墙门灯与单位映射、降级报告；目标软件真实导入仍列在剩余事项 |

完整工程备份与逐Floor双受众PNG在导出期间重检工程基线，阻止过期下载；文件和帮助菜单区分浏览器自动保存、工程备份与含秘密的主持人输出。

<a id="ocean"></a>
## 静态海洋

海岸和岩岛可追加海面、固定浪纹、舟船和生物布景。物件支持水面、水下及部分出水外观、波纹和静态尾流。简单船使用普通物件；船内共用普通Floor、房间、入口和家具，支持逐层编辑与总览。样板提供自然岸带的近岸海战、原尺寸远洋巨怪和三层船图。浅水与岸线共用地形曲线、羽化及材质覆盖；缺少原生Canvas模糊时，地表遮罩使用有界软件回退。海洋布景优先安排大尺寸图像，空间不足时明确列出缺项。动态海浪、船体航行及跨层寻路不在当前支持范围。

## 可选AI与共享工具

已接通流式聊天、受限草稿工具、参数助手，以及林中建筑的有限候选比较和指定房间家具修正。最终工程仍经用户审阅采用。手工编辑可以离线于模型运行；真实制作收益仍需比较。

AI面板分别说明普通文字对话、兼容后端与单独授权的草稿、图片流程查阅及拆件入口；截图复核另行征得同意。

应用与外部助手共用Git管理的工作流目录，可按步骤查询实际宿主能力、schema、效果与断点。地图CLI可交付完整工程，图片MCP可接续独立制作工作包。普通应用聊天尚无图片执行工具，目录出现某项能力不表示当前宿主已接线。

工作流自带的林中建筑预览及其来源数据保留在[示例数据](../workflows/examples/forest-building-20261117.json)。它只代表该固定输入；家具缺项、视觉签收和模型提效不能由预览存在推定通过。
