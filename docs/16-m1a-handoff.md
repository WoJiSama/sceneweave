## 2. 本批解决的设计问题

| 问题 | 交接约定 |
|---|---|
| 图片与组件是否是同一对象？ | 图片记录描述字节与像素；版本化定义给出建议外观、尺寸和语义；场景实例保存当前实际结果。换图默认保留物理占地和可见性 |
| 一个平面如何容纳高差？ | 地表覆盖解析唯一支撑面，离散高程表达高低台地；图层顺序只影响呈现。坡道/台阶显式连接，M1 不表达同一 XY 的桥上/桥下双通路 |
| 修改轮廓后哪些内容更新？ | 边缘、铺装裁切和阴影按来源派生；受影响的结构引用、连接锚点及锁在同一事务校验。人工物件位置保留，冲突需诊断 |
| 斜墙反转会使窗户漂移吗？ | v2 开口记录稳定的计量端点，反转墙不反转开口基准；无需把非整数墙长取整后重算位置。拆墙必须重新附着时才展示量化及引用变化 |
| 更新素材库是否改变旧地图？ | 工程内保存固定版本定义、参数和资源。目录新版本只能通过明确操作采用，已保存实例不随目录重建 |
| 再次散布是否覆盖手工成果？ | 保存全部结果和稳定成员关系；移动/替换覆盖、删除排除及锁定均持久化。再生成先形成候选，加载或绘制不重撒 |
| 新外观是否影响秘密？ | 先按受众过滤，再解析支撑面及外观。私密台地不能改变公开岸线、阴影、纹理相位或裁剪；玩家最终遮罩仍为必要检查 |
| 旧工程如何继续编辑？ | v1 在隔离副本上迁移，保留原件；程序符号不强制换素材，Region 不自动推断成地形。新格式不能降级保存成会丢语义的 v1 |

B2已有两处样板门口的有限检查，跟随当前门位置检查完整旋转占地及实体墙带/转角；冲突在预览/采用时整笔拒绝，配置与限制见04/08。预留区之外的家具碰墙、全图动线、门状态和B3高差通行仍未求解，不能据此关闭完整QA-GEO-04/05或QA-TERRAIN-02。

## 4. 素材交付与视觉评审

15是制作台账，所列目录 ID 与目标尺寸不表示资源已存在。M1-B 首先制作双样板共用的材质与单物件，再拼出书桌/露台组合及树石散布；混合场景所需补给与后续营地预演的帐篷按追加包准备，不阻塞两份小样板的第一次编辑验证。素材制作按ART-00至ART-03编号，与本文件的开发切片B1至B5区分。

每项实际资源至少要有可解码文件、内容 hash、实际像素与物理映射、占地/默认语义、来源/许可记录和样板试放结果；全部满足后才能标为可用。程序产生的图案同样要检查平铺、透明边缘、风格和细节，不能因容易制作就代替约定的美术质量。

视觉检查使用14规定的固定取景：整图、结构局部、材质局部、组件局部和4K输出；保留应用/素材/主题版本及实际缩放。记录哪些检查项达到目标、哪些需要返工。自动化几何与保存通过不能代替观感评审，静态好看也不能代替编辑和保密证据。
