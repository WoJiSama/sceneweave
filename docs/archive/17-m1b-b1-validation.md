## 1. 交付范围

从几何工坊左侧「素材」进入独立素材工坊，或打开本地地址 `/#assets`。当前可以：

- 创建「木纹书房」原创校样，使用一张重复木纹及透明书桌、椅子图片；实际位图与定义、许可完整保存。
- 修改独立物件的位置和旋转、房间底材方向；编辑先做完整领域校验，失败不提交。撤销/重做也增加 revision。
- 自动串行保存 v2 工程，同事务 CAS；最近 20 次成功保存的快照可恢复为新副本。冲突分支保留在内存中，可下载完整包或另存副本。
- 严格区分 v1/v2 工程。打开完整 v2 包先校验并预览确认，再创建新 sceneId；取消或失败保持当前工程。
- 从 M0 已保存修订或 v1 工程创建 v2 副本，保留实际来源 sceneId/revision、原始字节和 hash。原 `sceneweave-m0` 数据库不修改；新数据位于 `sceneweave-m1`。

v2 使用 `schemaVersion=2`、`containerVersion=2`、`profile=m1-assets`、`packageMode=complete`。它没有删字段降级到 v1 的路径。全部已采用定义也是资源闭包根，不能只打包当前画面可见的素材。

校样代码位于 `src/editor/v2/calibration.ts`，为本项目原创 Canvas 绘图，沿用 MIT 许可及来源记录。它的目录 ID 使用 `calibration.*`，没有冒用 `sceneweave-handdrawn@1`。15 中正式素材仍保持实际制作状态；校样没有经过 P3 美术验收。

## 4. 真实浏览器证据

### 资源与空仓库往返

40×24 的 PNG、JPEG、WebP 通过实际解码后绘入 sRGB Canvas，规范化为PNG；采用字节的 hash 一致，PNG/WebP 的透明角像素 alpha=0，JPEG为255。来源PNG的文本元数据被移除；完整包内未规范化的元数据PNG被拒绝。详见规范化记录（原附件已清理，旧路径：`docs/evidence/m1-b1/static-image-normalization.json`）。

原创校样完整包经导出、解析，在全新空 IndexedDB 创建副本，再页面重载、重新连接后：完整文档、三张实际位图 hash、许可与绑定一致，附加的主持人私密注记保留。此用例包约34 KiB，具体字节及每图尺寸见资源往返记录（原附件已清理，旧路径：`docs/evidence/m1-b1/complete-resource-roundtrip.json`）。压缩大小会随新 sceneId/时间等JSON内容变化。

| 位图 | 像素 | 规范化编码bytes |
|---|---|---|
| 重复木纹 | 512×512 | 11656 |
| 透明书桌 | 512×256 | 17409 |

## 5. 明确保留的边界

B1工作台只显示主持人内容，可能包含秘密；没有v2玩家投影或PNG入口。含尚未接入的地形、道路、主题描边/阴影、材质叠加或着色等特征时明确停止不完整预览，所有文档和资源仍可保存与备份。普通房间/墙门和符号预览仅用于迁移检查，不能替代B2建筑工具和视觉验收。

当前没有通用外部图片入库UI、素材目录搜索、主题切换、组合/散布成员编辑和生成、房间/岸线绘制、完整v2 CommandBatch API、通用空间寻路、AI、atlas/Worker、UVTT或PWA。普通地形/组合/散布可以被严格读取、校验和持久化，不等于有对应的编辑/生成/渲染工具。

迁移原件随本地迁移记录保留，支持单独下载；v2可移植完整包不夹带旧原件。完整包只包含新场景及其资源与许可，不把旧秘密副本附加进其他文件。当前没有资源GC或去重存储回收；裁剪最近20条快照不清除仍保留的资源字节。

候选大小/像素预算是前置拒绝策略；还没有双样板冷热三次测量、真实浏览器配额耗尽、跨浏览器/高DPR、峰值内存或完整恶意输入穷举证据。M0的4K隐私与程序符号负载回归通过，不能据此声称v2纹理玩家输出或真实性能通过。

QA映射见[09](../09-quality-plan.md)开头的B1子项表。QA-IMPORT-03、QA-VIS-01/02、QA-MAT-01、QA-COMP-01、QA-SCATTER-01、QA-SEC-06与QA-PERF-04仍需按完整定义验收。
