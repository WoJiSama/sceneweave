# 历史验收档案

这里保存已结束批次的设计交接、实现记录和测试报告。它们用于追溯当时的源码、失败、环境和边界，不是当前产品入口，也不覆盖后续冻结版本的结果。

日常阅读从 [上级文档导航](../README.md) 开始。当前主定义和现行验收入口只保留在顶层文档；历史报告中的“待完成”或“当前状态”只属于其记录批次。

| 范围 | 内容 |
|---|---|
| 13 | M0 几何版原型验证 |
| 16–33、35 | M1-A/B/C/D 的素材、建筑、室外、图层、恢复和联合验证；34 性能后续记录仍在顶层 |
| 36–44 | 首页、统一工作区、素材目录、内容批次和重构前全量回归 |
| 45 | M2 产品方向和首版范围；当前实施结果以顶层 05/07 为准 |
| 46 | 验收资料保留、清理和测试夹具迁移记录 |
| 47–52 | M2-0 统一完整 v1、共享核心、资源 IO、保全、素材库和原生工作区的分批交接 |

历史报告之间的相对引用仍按档案目录内的原始文件名保留；指向顶层 `docs/` 文档使用 `../`，指向仓库根目录的源码、测试、素材或工具使用 `../../`。
