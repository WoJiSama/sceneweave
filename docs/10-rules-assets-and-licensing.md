# 规则预设、素材与开源边界

状态：设计基线。最后更新：2026-10-20。规则与参考仓库来源见[调研依据](12-research.md)。本文件规定工程与内容管理方式，不代表已发行任何官方规则包。

## 通用预设先行

首版提供调查、战术、叙事三种使用预设。它们帮助选择格线、量尺、地点标注和注记组织，适合在 CoC、D&D、匕首之心的小团中使用，但不声称包含三套完整规则或官方认证。

| 预设 | 首版行为 | 后续规则内容边界 |
|---|---|---|
| 调查 investigation | 米制显示，可关格线；房间、线索和隐藏信息优先 | CoC 7e 使用场景参考，不内置官方模组与规则全文 |
| 战术 tactical | 常用 1524 mm 方格，门/障碍/净空提示 | 先以 5e 为范围；如引入具体规则，分别标明 SRD 5.1 或 5.2.1 |
| 叙事 narrative | 地标、危险与互动注记；抽象距离标签和可选精确量尺 | 匕首之心规则内容须按采用版本及 DPCGL 单独核验 |

预设可建议显示与新建默认值，但不自动改变已有墙、门、家具尺寸。显示单位与世界毫米坐标分别保存。用户对格线、吸附和显示单位的覆盖须可见，重开工程使用当时 presetSnapshot。

初版没有战斗回合、角色速度、技能成功率或自动规则裁定。掩体和危险是场景表达；若 UI 写“适合作掩体”，不自动产生某个体系的数值加成。

## 规则版本与可引用内容

| 来源 | 本轮已核实事实 | 对公开仓库的决定 |
|---|---|---|
| D&D 官方 SRD | 5.1 与 5.2.1 提供 CC BY 4.0 路线；完整商业内容不全部在 SRD 中 | 如分发 SRD 衍生内容，记录具体版本和要求的署名；不把官方设定/怪物图片一并当作可复用素材 |
| 匕首之心 SRD 2.0 | 地图章节同时包含距离段与可选方格；采用 DPCGL | 只实现通用可配置的空间工具；官方文字、数据和品牌用法作为独立内容发布决策 |
| DPCGL 2.0 | 私人小团使用与公开 Sharing 有区别；允许格式与 VTT 白名单另有条件 | 开源软件许可不自动覆盖官方内容；公开内容包按当时条款、目标分发形式核实 |
| CoC Quick-Start | 可免费获得，但版权页保留权利，允许范围包括特定游戏内复制 | 不随仓库发布规则书或官方冒险；使用原创调查场景与用户自备内容 |

不要以“个人团能用”推导“开源仓库可以分发”。只链接官方资源，当前仓库不收录其 PDF、插图、怪物表、角色卡或大量规则原文。用户导入自备内容时也不自动上传或生成公开素材包。

## 素材策略

首版先选一种统一风格：可读的平面图或简洁手绘。基础物件应覆盖门窗、床、桌椅、柜架、箱子、石块、帐篷、营火、桥面和地面材质，优先原创或明确允许再分发的 CC0 素材。暂不建设素材商店。

每个素材包提供以下清单；具体文件格式在进入素材实施阶段确定：

| 信息 | 要求 |
|---|---|
| 资产身份 | 稳定 ID、内容 hash、名称与类型 |
| 几何 | 原始像素、推荐真实尺寸、局部占地、锚点与朝向 |
| 玩法属性 | 默认是否阻挡移动/视线；主持人可调整，装饰默认不推断规则 |
| 作者与来源 | 创作者、原始来源链接或原创声明 |
| 授权 | 许可证标识/文本、署名方式、修改和再分发条件 |
| 文件嵌入 | 是否允许打包进入 .sceneweave 工程，是否仅限本地自用 |
| 生成素材 | 生成工具/模型标识、适用条款记录、人工选择与修改说明；不存密钥 |

素材被替换时实体尺寸与碰撞占地不能悄悄改变。需要按新素材重设尺寸时显示差异，由主持人明确采用。素材没有可靠授权信息时，可以保留本地自用导入标记，但不加入公开默认素材包；其实际使用仍取决于原有权利。

AI 图像生成属于后续功能。生成结果进入素材库时同样记录来源、使用条件和尺寸，不凭“AI 生成”宣称不存在第三方权利或可任意授权。首版模型生成文本默认属于主持人草稿，发布前由主持人选择内容。

## 公开发布清单

公开仓库当前只含原创设计文档、原创场景说明和必要元数据。未来增加实现或素材时检查：

1. 新内容的来源和许可证明确，署名/通知完整。
2. 规则内容版本和引用方式与许可匹配，公开工具与自备资料明确分开。
3. 默认工程与样例不含 API Key、私人聊天、用户模组、绝对本地路径或未授权素材。
4. 产品说明与当前实现一致，不把调研到的第三方能力写成本项目已完成能力。

项目名为“织境 · Sceneweave”，仓库名 sceneweave，尚未完成正式商标检索。公开仓库名称可用不等于确认商标权；这是品牌发布前的待办，不妨碍当前文档与开发准备。
