# 素材、画面与许可

## 画面与物理

目标是协调的二维俯视地图：线条、视角、真实尺寸、纹理尺度、细节密度和光向一致。按整图需求组织素材和功能，样板用于发现共性问题，不按样板ID添加专属布局。自然地形先处理大形、通路和支撑，再补边缘、植被和光影。

图像大小、透明留白、根锚和物理占地分别标定。换材质/颜色/阴影不暗改碰撞、净宽、高程或秘密；桥、船、楼梯图片不自动产生通行。美术判断要看实际全景、近景及移动/旋转效果，技术通过不能代用户签收。

## 素材身份与导入

固定物件、材质、组合、模板及其派生保留稳定身份、版本、实际字节/hash、原始来源、父版本和确切许可。新语义使用新固定内容，不能覆盖旧身份；已有工程、历史和个人库不因停止发现某素材而丢失资源。

每份素材应有名称/类型、像素尺寸、真实毫米范围、占地/锚点、物理默认值、作者/来源、完整许可、署名及允许嵌入的范围。组合和主题包继承全部成员要求，重组、转PNG或AI改画不会自动消除权利限制。

普通导入支持图片、受限SVG、文件夹与`sceneweave-assets.json`清单ZIP。实际格式、预算、名称、尺寸和批量操作见[导入指南](reference/asset-import.md)；准确限制由实现校验。个人库备份与完整工程备份各自独立，导入不会自动公开或上传。

带发布者的清单以发布者、包标识、版本和内容 SHA-256 固定引用。摘要使用完整清单的规范 JSON（对象键排序、数组保序、UTF-8），其中包括各素材的原始字节摘要、物理参数和许可。导入逐项核实实际字节；宿主传入固定引用时，四项须全部匹配。签发审核和采用工程候选仍由各自入口执行。

## 权利与公共分发

原创代码和文档采用根目录[MIT License](../LICENSE)。素材及依赖按各自许可证处理，不能把仓库MIT延伸到外部图片、规则书、字体或参考项目。

公开再分发、修改、成图输出和嵌入工程/素材库是分别核对的权利。用户需提供真实署名和完整许可，并明确确认相应用途；可以下载、个人团能用或自称原创，都不能代替公开分发授权。参考截图和私有地图不进入公共默认包。

个人导入只需满足实际技术/来源/嵌入约束，不等待公共包美术签收。公共默认主题则分别检查权利、技术、美术及完整场景用途，并由用户签收确切内容。外来审核JSON是声明，不自动形成可信批准；技术通过、作者自报和用户签收不能互代。

素材包保留各自SVG、PNG、manifest、许可和说明，例如[室内](../assets/sceneweave-handdrawn/README.md)、[室外](../assets/sceneweave-handdrawn-outdoor/README.md)、[哨所](../assets/sceneweave-handdrawn-outpost/README.md)及[主题内容](../assets/sceneweave-handdrawn-content/README.md)。不因删除开发台账而删除这些权利/固定来源数据。
