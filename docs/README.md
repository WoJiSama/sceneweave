## 验收与复现

- 最终验收只从[55统一入口](55-terrain-generation-design.md#terrain-acceptance)开始；Q4与地形AI按需求覆盖合并，独立任务不重复计数。
- 运行、配置与部署见[贡献说明](../CONTRIBUTING.md)；具体用例见[测试说明](../tests/README.md)。
- 已有失败和测试/发布记录从[历史索引](archive/README.md)追溯，不把旧通过数视为当前新验证。
- 修复后复验影响范围；共用算法或素材变化时重跑受影响任务组。

同一个事实只留一个主定义，其他页面引用它。新增文档应先确认现有主题无法承载；不再复制长状态段落、测试数字和交付流水。`todo.md`保持用户独立清单。
