顶层保留 18 份现行主题文档，37 份历史批次文档移入 [archive](archive/README.md)。日常从本页、[路线图](07-roadmap.md)和当前任务对应的主定义开始；历史报告用于追溯当时的实现、失败和测试边界。

## 当前状态

当前主线是 **M2-E 交付前验收收口**，顺序为：

`M2-E 验收收口 → M3 真实小团 → 发布与后续维护`

M2-E 包含真实模型任务、P3 视觉签收、正式性能、无引导场景、UVTT 真实导入，以及配额和未覆盖输入。它们完成，或形成明确的阻塞、限制试用或延期决定后，才进入 M3。当前代码和技术验收结果分别见 [07 路线图](07-roadmap.md)、[54 参考图质量计划](54-reference-quality-plan.md) 和 [55 地形设计](55-terrain-generation-design.md)。

当前确认的边界：

- T0–T7 当前实现范围内的统一技术验收已完成，包括复杂拓扑、近侧视与区域下钻；范围、失败和复验记录见 [55 第20节](55-terrain-generation-design.md#20-t4t6实现与t7收口边界)。T2 有限编辑另有聚焦复验，见 [20.10节](55-terrain-generation-design.md#2010-2026-10-28-t2聚焦复验)，不据此关闭 M2-E。
- M2-3/4/5 的结构、SVG、任务后端和线上必要旅程已经实现；Q4 真实 GLM 视觉/创作验收和 Q5 最终收口仍未全部完成。
- `todo.md` 是独立的想法清单，不是当前交付清单，也不随本导航自动纳入提交。

## 术语

| 术语 | 含义 |
|---|---|
| GM / 主持人 | 可访问完整工程、秘密和线索的人 |
| 玩家投影 | 过滤秘密后的临时输出，首版为 PNG |
| SceneDocument | 与渲染引擎无关的完整可编辑场景模型 |
| revision | 成功事务的单调修订号，撤销后也不会倒退 |
| editLocked / locked | 编辑锁与门窗通行锁，两个概念独立 |
| Proposal | 尚未通过本机校验和主持人采用的建议 |
| 材质 / 主题 | 外观协调规则，不替代占地、通行或秘密属性 |
| 组合 | 固定版本和完整成员组成的可编辑对象集合 |
| 散布 | 按区域、密度、间距和排除条件生成并持久化的对象结果 |
| 离散高差 | 同一 Floor 内的地面高度差，不等于多层 3D 楼层 |
| 风格同化 | 对明确目标协调外观，保留原件、成员、物理和秘密字段 |

## 当前产品边界

当前产品使用统一完整工程工作区和 `sceneweave-projects` / `sceneweave-library`。旧整页工作台、旧首页发现和旧格式转换入口已经退役；底层兼容代码和历史报告保留用于数据、测试或证据追溯。建筑、室外、组合、图层、外观、快照、有限恢复、AI 草稿、SVG 和本地 PNG 已接入当前主路径，但每项仍以 07、09、34、54、55 中的验收状态为准。
