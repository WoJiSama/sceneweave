## 1. 本批改变

在「素材工坊」打开任一样板或自己的完整工程，点击「校验完整工程」，查看位图、固定定义和许可摘要。打开不完整或损坏的工程时，会列出相关对象、固定依赖、图片 SHA-256 或包内文件；修复后可重选文件。失败或取消不产生占位工程，也不替换当前工程与存档。

| 改变 | 实际行为 |
|---|---|
| 结构化诊断 | 正式导入、导出、存储校验复用严格规则；`ProjectValidationErrorV2.issues`保留机器码与对象/依赖身份，诊断API不产生可采用候选 |
| 多缺项清单 | 聚合缺定义、固定版本不符、缺位图、缺许可/绑定与禁止嵌入问题；结构或依赖无效时不进入解码 |
| 有界展示 | 最多256项（包含截断说明），超出明确记录未展示数量；Error字符串只摘要前8项，不能把未展示解释为忽略校验 |
| 字节与解码失败 | hash/ZIP CRC/PNG CRC/元数据/原生解码失败携带包内path或图片hash；字节、编码和解码仍遇首项失败停止 |
| 取消与状态 | 保持AbortError；取消在途准备后迟到位图被关闭，当前修订、历史、存档与输入文件保留 |
| 应用版本 | manifest应用版本直接读取package.json，修正此前硬编码B1标识；格式/容器版本不变 |

诊断仅面向主持人；换修订、工程或受众后清理旧结果。打开文件或最近工程会先退出玩家预览并清理旧清单，使失败可见；失败不改变工程数据。错误不输出私密正文、原始提示词、原生解码器详情或外部源文件路径。完整包仍需全部依赖齐全；没有“忽略错误继续导入”、自动下载、缺图重关联或不完整预览。
