# 有限修改现有场景

## inspect
读取本次真实工具schema与已授权场景摘要，确认当前草稿基线、范围、锁、固定资源及预算。普通聊天只能指导页面操作；没有创作授权时不尝试编辑。

## edit
使用宿主实际暴露的有限原子操作，小步形成候选。复制真实工具返回的身份和参数；遇到约束拒绝先查看原因，避免连续猜坐标、支撑或同一失败。不得改变范围外内容或绕过人工保护。

## check
运行已开放的草稿检查并读取真实诊断和差异。领域通过与视觉通过分别记录，列出未满足要求。受影响输入变化后旧候选和审核失效，继续前读取当前身份。

## adopt
主工程的本机资源检查、保护、CAS与一次采用由现有页面负责。模型不直接写主工程。取消、保存或采用失败保留草稿及当前成果，交付明确可继续的断点。
