# 墨绘原野 · 墓园、火山与自然精修候选

这些是本项目原创、可编辑的 SVG 插图及其实际 PNG 派生，保持 **O / P2 候选**。不据技术检查、开发者查看或目录收录推定主题 P3、用户美术签收或完整场景验收。

墓园首批为苔痕旧石板、细砾土、严格俯视墓碑顶盖、石棺和短段铁栏；火山首批为冷却玄武岩、细火山灰、冷壳熔岩、气孔岩块和余热裂隙装饰。物件俯视，不画可误解为正立面的墓碑碑文。熔岩、裂隙和炉火图片只表达外观，不能自动授予危险、通行、热量、光源、支撑或高差。

自然精修包含阔叶树冠、圆叶灌丛、碎石簇、草地、裸岩和砂地。每件采用新的 `catalogId`（原 ID 后加 `.refined`）及固定版本 1；原 SVG、PNG、固定定义和旧工程保持。`refines` 记录原目录、固定版本与原位图 SHA-256，`provenance` 另记确切旧 SVG 来源和 hash。精修件的整幅像素、逻辑尺寸、视觉矩形、占地/偏移、阻挡和渲染/阴影类别从旧 manifest 原样保留；不因增加叶片或纹理改变通行。

随后为 M1-D 的 SCN-01 布景续批增加挂衣木架、长凳、炉台、操作桌、边柜、单人床和衣柜。各有独立原创图片和完整物理元数据；未把旧桌椅改名冒充这些物件。床铺、封闭柜顶和工作面均采用顶视；炉台不创建可进入房间或实际光源。

复现入口为 [`tools/build-themed-art.mjs`](../../tools/build-themed-art.mjs)：

```sh
node tools/build-themed-art.mjs --preview
```

生成器使用确定性种子的矢量轮廓、可编辑纹理/刻线及低强度 SVG 纸质噪声，Chrome 原生 sRGB Canvas 栅格化。未使用外部图像、描摹、字体、图片组件或图像生成服务。代码不从外部网站取图。

- 本目录保留 SVG、MIT 原文及 manifest；实际 PNG 位于 `public/assets/sceneweave-handdrawn-content/`。
- 两处 manifest 和 LICENSE 相同。manifest 逐件记录实际源/PNG SHA-256、文件字节、整幅尺寸、毫米元数据和实际 alpha 范围。
- PNG 为 RGBA8、sRGB、straight alpha，只保留 IHDR/sRGB/IDAT/IEND 块，alpha=0 时 RGB 归零。透明物件至少留 8 源像素外围留白；材质全不透明。
- 不烘焙长方向投影；物件体积由本体刻线与局部材质表达，地图环境阴影由既有渲染器在受众过滤后生成。
- 个人整理标签/颜色独立于固定图像内容；本包 tags/colors 只是人工发布者描述，不是图像自动识别，也不写玩法含义。
- 目录与实际小构图、应用和简单检查结果由本批开发报告记录。素材接缝查看和开发者视觉筛查不替代用户最终观感评审。
