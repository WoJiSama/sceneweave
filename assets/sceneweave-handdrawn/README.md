# 墨绘原野 v1 · 室内候选包

本批包含 4 张地表材质与 11 张透明物件 PNG，以及全部可编辑 SVG 源文件。由 Sceneweave contributors 以 Codex 辅助原创编写 SVG 图形，采用本目录 [MIT 文本](LICENSE.txt)。没有提取、描摹或转换用户参考图中的图片、轮廓、布局或商业素材，没有调用图像生成服务。书房与露台的布局来自项目原创 VIS-01 规格。

当前制作状态为 **P2 待验收**。静态字节、尺寸、sRGB、透明区、占地映射和许可记录可复核；P2 不等于视觉评审、完整样板、性能或默认目录的发布验收已经完成。正式入库状态由制作清单与对应运行报告记录。

`manifest.json` 保存逐项目录身份、真实 PNG sha256、字节数、像素尺寸、物理尺寸、视觉边界、占地/语义、透明像素包围和留白。公共运行文件在 `public/assets/sceneweave-handdrawn/`，完整 `.sceneweave` 工程保存采用后的全部图片字节、定义快照与许可，不依赖此 URL 或旧浏览器缓存。

从仓库根执行：

```sh
node tools/build-study-art.mjs
```

生成器使用已安装的桌面 Chrome，经 Playwright 将原始 SVG 渲染到 sRGB Canvas，再由确定的无元数据 PNG 编码器写出 8-bit RGBA、straight alpha、sRGB 字节。完全透明像素的 RGB 清零，透明物件边缘至少保留 8 源像素。所需绘图与编码代码全部在仓库内；Chrome 版本可能影响抗锯齿，所以更新构建环境后的新字节需要重新评审，不能静默改写已采用工程的版本快照。

纹理以 256 px/m 制作。木板为每 2 m 8 板、板宽 250 mm、板长 1000 mm、错缝 500 mm，未旋转纹理的板长沿世界 +y；两种木材共用接缝相位。露台石板为每 2 m 4×4 格、标称 500 mm、缝宽 12 mm。纹理中没有墙体阴影；物件中没有长投影或固定方向高光，环境投影由保存的主题参数在过滤受众后绘制。

视觉图像的透明边界不决定玩法。桌、椅、书架、花盆采用各自毫米占地；书纸、地毯、桌灯和信封为非阻挡装饰。换椅子变体不改变占地、阻挡和实例尺寸。组合为真实成员，不是一张整组贴图。
